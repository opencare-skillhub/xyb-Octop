# 病历脱敏

患者上传的资料里，**真正需要保护的往往不在医学内容里，而在边角**：页眉的姓名、住院号、条码、二维码、医生签名、缴费单号和医院名称。

这个技能解决两件事：

1. **遮什么、怎么遮**（可执行清单与模式）；
2. **遮完能不能外发**（不能默认外发）。

## 一、先分清三件事

| 类别 | 例子 | 处理 |
|---|---|---|
| **身份标识**（必须遮） | 姓名、身份证号、手机号、住院号/门诊号、病案号、医保卡号、银行卡号、地址、工作单位 | 遮成占位符 |
| **医学内容**（要保留） | 诊断、分期、病理、化验数值、影像描述、用药、基因变异 | **保留原样**——这是分析的基础 |
| **准标识**（看场景） | 出生日期、就诊日期、医院名称、主治医生姓名、罕见病+地区组合 | 默认遮日期与机构；需要时间趋势时只保留年月 |

**关键判断**：如果一条信息「换个人就不成立」，它大概率是标识而不是医学内容。

## 二、必须遮的字段与识别模式

以下模式可直接用于本机脚本或检索（正则语法通用）：

| 字段 | 模式 | 占位符 |
|---|---|---|
| 手机号 | `1[3-9]\d{9}` | `[电话_手机]` |
| 身份证号 | `\d{17}[\dXx]` | `[身份证_1]` |
| 邮箱 | `[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}` | `[邮箱_1]` |
| 日期 | `\d{4}[-/年]\d{1,2}[-/月]\d{1,2}日?` | `[日期_1]`（需要趋势时保留 `YYYY-MM`） |
| 固定电话 | `0\d{2,3}-?\d{7,8}` | `[电话_固话]` |
| 数字编号串 | `\b\d{6,12}\b` | `[编号_1]` |
| 银行卡号 | `\b\d{13,19}\b` | `[银行卡_1]` |
| URL | `https?://\S+` | `[链接_1]` |

**正则抓不到的部分必须人工过一遍**，这是最容易漏的地方：

- 姓名（中文姓名没有可靠正则）；
- 医院名称、科室、主治医生姓名（在正文里出现，不在页眉）；
- 手写体、印章、签名、**条码与二维码**（二维码里常含住院号）；
- 图片里的信息（需 OCR 或手工遮挡）。

## 三、执行顺序（不要颠倒）

1. **先复制再处理**：原件放本机，另存一份用于脱敏，不要改原件。
2. **先文档后图片**：文本类（PDF/DOCX/MD）先跑模式替换；图片类需要 OCR 或手工遮挡。
3. **图片要覆盖而不是模糊**：模糊可逆风险高，用实心色块覆盖。
4. **二维码与条码直接涂掉**（不要试图解析后选择性去除）。
5. **元数据也要清**：PDF/DOCX 的作者、修订记录、路径、GPS；图片的 EXIF。
6. **脱敏后再自查**（见下一节）。

## 四、脱敏后自查（逐条过，缺一条就不算完成）

- [ ] 全文搜索是否有漏网的姓名（**用患者真实姓名搜一遍**）
- [ ] 身份证 / 手机号 / 住院号 是否有残留（正则再跑一遍）
- [ ] 页眉、页脚、水印、页边批注查了吗
- [ ] 图片、截图、扫描件里的文字与条码遮了吗
- [ ] 文件元数据与文件名清了吗（**文件名常含姓名**）
- [ ] 导出件的文件名、标题、内嵌属性检查了吗
- [ ] 用一份「去掉身份信息后仍能读懂」的标准复核：医学内容有没有被误遮

## 五、硬边界

- **脱敏不等于可以外发。** 遮掉身份信息不代表可以上传到公网、发到群里或提交给第三方。
- **默认全部在本机处理**，不上传、不投喂到外部服务、不写进日志。
- **不收集**：不需要的治疗信息不要索取；不主动要姓名、身份证号、住院号。
- **不承诺绝对安全**：能说「已按清单遮盖并自查」，不能说「已完全匿名、绝对安全」；罕见病 + 地区 + 年龄的组合仍可能反推身份，这一点要讲明。
- **患者要求删除时**：按其要求删除本机留存的资料，不做「已同步到别处」的隐瞒。

## 六、与其他技能的配合

| 场景 | 配合方式 |
|---|---|
| 患者要整理一堆资料 | 先按本技能遮，再走 `case-summary` 对齐摘要 |
| 使用专家包里的病案整理技能 | 在归档**之前**先跑脱敏；归档产物也按本节自查 |
| 涉及上传到会话 | 提醒患者：遮掉姓名、住院号、身份证号、电话后再上传 |
| 涉及第三方平台 | 先说明「遮了也建议不要外发」，由患者决定 |

## 七、措辞纪律

- 说「我已按清单遮盖并自查」，不写「已完全匿名」；
- 说「建议先遮这些再发给我」，不写「随便发，我会处理」；
- 说「这条信息我不需要，请打码」，不写「把身份证号发我核对」。
