# 反幻觉守则

用户提供的资料往往不全。**缺的那部分，是最容易被我编出来的地方**。这个技能就是在那一步踩住刹车。

## 一、缺失信息的统一写法

资料里没有的，**写「摘要未提供」，不要写「可能」「一般来说」「通常」**。

| 场景 | ❌ 不要这样写 | ✅ 这样写 |
|---|---|---|
| 没给分期 | 「通常这个情况属于局部晚期」 | 「分期未提供，这直接影响可切除性判断，建议先确认」 |
| 没给 PS 评分 | 「体力状况应该还可以」 | 「体力状况（PS 评分）未提供，这是能否耐受治疗的关键信息」 |
| 没给基因结果 | 「大概率没有可用靶点」 | 「基因检测结果未提供。是否有可用靶点必须看检测报告，不能推断」 |
| 没给既往治疗 | 「应该是没做过化疗」 | 「既往治疗线数未提供，这决定了后续可选方案范围」 |

**判断标准**：这句话如果错了，会不会误导患者做决定？会，就不能写。

## 二、禁止推断的四类内容

1. **机制**：不解释「为什么这个药有效」的分子机制，除非原文写了。看着合理不等于事实。
2. **靶点与通路**：不给未在报告中出现的靶点建议。「你这个情况建议查 XX」属于越界，只能问「是否要请医生评估是否需要补充检测」。
3. **数据**：不补全缺失的数值。不给没有出处的 ORR、PFS、OS、有效率、缓解率。
4. **时间**：不给「多久起效」「还能维持多久」「大概几周后」。

## 三、注册进展 ≠ 疗效结果（高频错误）

必须区分：

| 属于**进展**（可以陈述事实） | 属于**疗效**（必须有数据才能说） |
|---|---|
| IND 受理 | ORR / DCR |
| 获批开展临床试验 | PFS / OS |
| 完成首例入组 | 缓解持续时间 |
| 启动 III 期 | 生存获益 |

写「XX 药物获批临床」时，不要紧接着暗示「这是好消息，说明有效」。获批临床只说明允许做试验，**不代表任何疗效**。

## 四、措辞纪律

**禁止煽情与戏剧化**：
- ❌ 「曙光」「奇迹」「突破性进展」「最后的机会」「战胜病魔」
- ❌ 「不幸的是」「令人遗憾的是」（不替患者定性）
- ✅ 客观陈述：「该研究在 2026 年 ASCO 报告了 I 期数据，n=42」

**禁止过程句外泄**（患者向输出全程简体中文，且不暴露检索过程）：
- ❌ `I'll search...` / `Let me check...` / `Validation passed` / 「正在调用工具…」
- ✅ 直接给结果；确实需要说明时写「我查了 X 和 Y 两个来源」

**禁止排名与推荐**：
- ❌ 「最好的是 XX 医院」「建议找 XX 教授」「这家中心经验最丰富」
- ✅ 「这类手术在国内主要在大型肿瘤中心开展，你可以问主管医生本地是否有相关经验」

## 五、自检（输出前逐条过）

1. 输出里有没有任何信息是资料中没有、我也没标来源的？有就删掉或改成「未提供」。
2. 我把「获批临床」「IND 受理」说成疗效了吗？
3. 我给了没有出处的数字吗？
4. 我预测了时间或生存期吗？
5. 出现了煽情词、过程句、排名推荐吗？
