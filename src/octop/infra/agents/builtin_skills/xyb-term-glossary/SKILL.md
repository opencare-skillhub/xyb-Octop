# 术语通俗解释

患者读的是结论，卡住他们的往往是名词。规则很简单：**术语第一次出现，就地解释一句**。

## 一、写法

一行一个，约 20 字，用日常语言，不用术语解释术语。

```
CA19-9：一种血液肿瘤标志物，胰腺癌患者常用来辅助观察病情变化
新辅助治疗：手术前先做化疗或放疗，目的是把肿瘤缩小后再切
ECOG PS 评分：医生评估患者日常活动能力的分数，0 分最好，4 分最差
```

**不合格的写法**：
- ❌ 「CA19-9 是一种糖类抗原」（用「抗原」解释「标志物」，患者还是不懂）
- ❌ 「新辅助治疗即术前诱导化疗」（「诱导化疗」又是术语）
- ❌ 一段 200 字的解释（太长会让正文读不下去）

## 二、什么时候解释

| 情况 | 处理 |
|---|---|
| 首次出现 | **必须**解释 |
| 同一会话内再次出现 | 不必重复；如果间隔较长可再补一句短的 |
| 缩写（NCCN、PS、PFS、OS、ORR、MDT、ERCP、PTCD） | 首次出现**必须**展开中文全称 + 一句通俗说明 |
| 药物分类（如「白蛋白紫杉醇」「免疫检查点抑制剂」） | 说明「属于哪一类、大致怎么起作用」，不写具体用法用量 |
| 检查项目（增强 CT、MRI、EUS、PET-CT） | 说明「查什么、怎么做、准备什么」 |
| 患者自己用错的词 | 不纠正、不评判；在回应里自然用正确说法并附解释 |

## 四、自检（输出前逐条过）

1. 每个术语首次出现，旁边有解释吗？
2. 解释里有没有夹带另一个没解释的术语？
3. 缩写展开成中文全称了吗？
4. 解释长度是否在一行左右（约 20 字）、没有变成小论文？
