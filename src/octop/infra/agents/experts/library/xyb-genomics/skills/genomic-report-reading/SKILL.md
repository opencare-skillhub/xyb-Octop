# 基因报告逐项解读

基因报告最容易造成两种误解：**检出某个变异就以为有药可用**，或者**全阴性就以为没希望**。这个技能就是在这两处刹车。

## 一、先看方法学（决定结论的边界）

| 要确认的 | 为什么重要 |
|---|---|
| 样本类型 | 组织 vs 血液；血液 ctDNA 阴性不能排除组织有突变 |
| 检测方法 | 小 panel / 大 panel / 全外显子 / 全基因组；覆盖范围决定「没检出」的含义 |
| 检测机构与时间 | 报告时效性；有些结果需要复测 |
| 肿瘤细胞含量 | 含量过低会导致假阴性 |
| 是否含胚系分析 | 很多 panel 只报体系变异，不主动分析胚系 |

**报告没写这些，就要在输出里标注「方法学未提供」，并说明这会限制结论强度。**

## 二、逐项解读的字段

对报告里每一条变异，按顺序说清：

1. **基因名**（如 KRAS、TP53、BRCA2、CDKN2A、SMAD4、ARID1A…）
2. **变异类型**：点突变 / 插入缺失 / 融合 / 拷贝数改变 / 甲基化
3. **氨基酸改变与位置**（如 G12D）
4. **等位基因频率（VAF）**——提示是体系还是胚系
5. **来源**：体系（肿瘤获得）还是胚系（可遗传）
6. **报告给出的意义分级**：致病 / 可能致病 / 意义未明（VUS）/ 可能良性 / 良性
7. **可讨论的方向类别**——**只给方向类别，不给药名**

## 三、三档区分（输出必须明确归类）

| 档 | 判据 | 怎么对患者说 |
|---|---|---|
| **可操作** | 报告给出明确分级，且有对应的治疗方向类别 | 「这一项在报告里被标为有临床意义，对应可以跟医生讨论的方向是……，具体能不能用要医生判断」 |
| **意义未明（VUS）** | 报告标 VUS | 「这一项目前**不能**用来指导治疗。它只是「目前证据不足」，不是「有问题」。以后证据积累可能改变结论」 |
| **阴性 / 未检出** | 报告写野生型或未检出 | 「说明这个方法覆盖的范围内没发现该变异。这不等于没有治疗方向，也可能是检测范围或样本质量限制」 |

## 四、胚系变异要额外做的事

检出胚系变异时，**必须**补充一段，但不得替家人判断风险：

> 这份报告提示存在**可能可遗传**的变异。这不等于家人一定会患病，但**建议你和家人咨询遗传咨询门诊或主管医生**，由他们评估是否需要为家人安排检测与随访。我无法替家人判断风险。

## 五、输出格式

```
【基因检测报告解读】

一、方法与边界
   - 样本 / 方法 / 覆盖范围 / 肿瘤细胞含量：…
   - 未提供的方法学信息：…

二、检出结果（逐项）
   1. <基因> <变异> | 体系/胚系 | VAF | 报告分级 | 可讨论方向类别
   2. …

三、意义未明变异（VUS）
   - <列出，并明确说明不能用于指导治疗>

四、阴性 / 未检出
   - <明确说明含义与局限>

五、可以问肿瘤内科医生或遗传咨询师的问题（3–5 条）

六、需要提醒的事
   - <胚系相关提示，如适用>
```

## 六、红线

- ❌ 不得把变异直接翻译成用药建议或药名
- ❌ 不得对 VUS 做任何「可能有用」的暗示
- ❌ 不得替家人判断遗传风险
- ❌ 不得重新判读原始测序数据（我看的是报告结论）
- ✅ 每个变异都要给出来源与分级，缺就给「报告未标注」
