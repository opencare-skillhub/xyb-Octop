# 影像报告字段解读

影像科报告有固定结构。患者读不懂的通常不是词，而是**为什么医生只关心其中几行**。

## 一、报告的基本结构

| 部分 | 内容 | 患者常误解的地方 |
|---|---|---|
| 检查方法 | 平扫 / 增强、扫描范围、是否用对比剂 | 「增强」不是病情加重，指打了对比剂 |
| 主要所见 | 对每个器官的描述 | 这里出现的所有描述不一定都与主病相关 |
| 关键描述 | 病灶位置、大小、与周围结构关系 | **这一段才是影响判断的核心** |
| 印象 / 结论 | 影像科医生的归纳 | 这是影像判断，不是病理诊断 |
| 建议 | 复查间隔、建议进一步检查 | 建议不等于诊断 |

## 二、必须逐项对照的关键描述

面对患者提供的报告，按这个清单找，**找到就打勾，找不到就明说「报告未提及」**：

1. **病灶位置**：胰头 / 胰体 / 胰尾 / 钩突；是否跨区
2. **病灶大小**：三个径线或最大径
3. **与血管的关系**（最关键）：
   - 肠系膜上动脉（SMA）——接触角度、有无包绕、有无狭窄
   - 肠系膜上静脉（SMV）／门静脉（PV）——接触、变形、闭塞、有无可重建
   - 腹腔干（CA）、肝总动脉（CHA）
4. **周围侵犯**：十二指肠、胆总管、脾血管、胃
5. **转移情况**：肝、腹膜、肺、远处淋巴结、腹水
6. **胆道与胰管**：扩张程度、有无结石
7. **血管变异**：有无替代性肝动脉等（影响手术规划）
8. **对比既往**：新增、增大、缩小还是稳定

## 三、输出格式

```
【报告字段解读】

一、这份报告包含什么
   - 检查类型：…
   - 主要所见涉及：…

二、与判断相关的关键字段
   ✓ 已写明：<逐条摘录报告原话>
   ✗ 未提及：<逐条列出，并说明为什么它重要>

三、需要向医生确认的表述
   - 报告里的「接触」具体指多少度？（不同中心界值不同）
   - …

四、可以问影像科或主管医生的问题（3–5 条）
```

## 四、红线

- ❌ 不读片、不推测图像上「看起来像什么」
- ❌ 不下影像诊断结论，不给分期结论
- ❌ 不评价设备或扫描质量「好不好」
- ❌ 不比较不同医院的结果孰优孰劣
- ✅ 报告没写的，一律写「报告未提及」

## 五、随访对比的注意点

不同设备、不同扫描方案、不同期相的测量结果**不宜直接相减**。对比时要说清「这不是严格的同条件对比，结论以影像科医生的对比阅片为准」。
