> **上游种子**：[ch21 浮世绘（芳年）](../chapters/ch21-浮世绘.md) · [ch18 当代艺术（基弗）](../chapters/ch18-当代艺术.md) · [moods/08 暗黑崇高](../moods/08-暗黑崇高.md)

## 部署提示词

```text
以「哥特暗黑」基因渲染本产物：
- 色彩：铅灰黑底 #12100e（褐倾向）；骨白 #e8e2d5 做文字；
  点睛只允许一种：血红 #8b1a1a 或 月白 #cdd5e0（二选一，全局统一）；
  灰阶丰富（铅/烬/褐三向黑），禁正黑 #000
- 形：尖拱（哥特窗形 clip-path）做图片框/卡片顶；细长比例（竖长卡片 1:3）；
  铁艺细线装饰（1px 卷纹 SVG 一处）；禁圆润可爱形状
- 字：标题黑长衬线（Cinzel/思源宋 Black）+ 大字距；正文骨白 15px+；
  数字用雕刻感衬线；禁圆体禁手写可爱体
- 排版：中央对称的仪式感（哥特教堂立面逻辑）或大留白压迫（废墟逻辑）二选一；
  一屏一个恐怖符号放大，禁符号堆叠；分隔线用荆棘/锁链纹一次
- 禁：霓虹色（那是赛博的语言）；恐怖元素超过一种/屏；低对比灰字
```

## CSS 变量块

```css
:root {
  --bg:#12100e; --surface:#1a1712; --bone:#e8e2d5;
  --blood:#8b1a1a; /* 或 --moon:#cdd5e0 二选一 */
  --line:#3a342a;
  --radius:0px;
  --arch:clip-path: polygon(0 30%, 50% 0, 100% 30%, 100% 100%, 0 100%); /* 尖拱框 */
  --font-serif:'Cinzel','Noto Serif SC',serif;
}
```

## 反模式

- 恐怖符号+血迹+乌鸦+蜘蛛同框（万圣节超市化）；荧光点缀混入
- 纯黑平涂无质感（要有铅灰/烬褐的物质感）
