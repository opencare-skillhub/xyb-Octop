> **适用产物**：暗色 dashboard、科技产品长图、开发者工具官网、游戏 HUD
> **上游种子**：[ch22 动漫风格](../chapters/ch22-动漫风格.md) · [moods/01 科技酷感](../moods/01-科技酷感.md)

## 部署提示词

```text
以「赛博霓虹」基因渲染本产物：
- 色彩：深蓝黑底 #0a0e1a；浮起面 #131b2e；正文 #c9d1d9；
  荧光青 #38f2c8 只做强调/链接/数据高亮（面积 ≤15%）；品红 #ff2d78 只做告警；禁紫色渐变
- 光：一切亮部"自发光"——焦点元素配 box-shadow 辉光，普通元素禁辉光；
  背景 5% 透明度细网格线纹理做纵深感
- 形：圆角 4-6px 锐利系（禁 12px+ 软萌圆角）；1px rgba(56,242,200,.25) 描边代替实线边框
- 字：数据/代码用等宽（JetBrains Mono 类）；标题紧凑无衬线 600+ 字重；禁衬线禁圆体
- 排版：不对称栅格 + 大号数字编号；模块间 24px 起；状态用「呼吸辉光」一处点睛
- 禁：粒子满天飞、多重辉光叠满屏、正文用荧光色（荧光只给边、线、数字）
```

## CSS 变量块

```css
  --accent:#38f2c8; --danger:#ff2d78;
  --radius:6px; --line:rgba(56,242,200,.25);
  --glow:0 0 12px rgba(56,242,200,.35);
  --mono:'JetBrains Mono','SF Mono',monospace;
}
```

## 反模式

- 荧光色 ≥3 种（廉价夜店风）；等距卡片三连（AI 味）
- 死黑 #000 大平涂（要有蓝紫倾向的深底）
- 正文低对比灰字（对比度 <7:1）
