# 🎨 code-gene · 极简主义（留白即豪华）

> **激活词**：Donald Judd、Agnes Martin、Ellsworth Kelly、less is more、gallery white、日式 MA（間）
> **适用产物**：高端产品页、作品集、发布页 hero、品牌声明页、摄影展示
> **上游种子**：[ch17 极简主义与观念艺术](../chapters/ch17-极简主义与观念艺术.md)

## 部署提示词

```text
以「极简主义」基因渲染本产物：
- 色彩：白底单字黑（#111 正文 #fff 底）+ 至多一个点睛色块（Kelly 式单色面，可做整块 section 背景）；
  灰阶只许 2 级（#111/#888）
- 形：内容即盒子——1px 边框或纯色块，无阴影无圆角（或 0/24px 二选一，禁中间态）；
  图片直角展示不加描边
- 字：单字体家族，两个字重（400/600）；超大标题（64-120px）+ 极小注释（11px）的大小反差是本基因的张力来源
- 排版：留白占比 ≥50%；一屏一个信息主体；垂直居中或极端不对称（贴边）二选一；
  导航极简到只剩 3-4 个词
- 禁：三个卡片并排、任何"丰富"的冲动——每多一个元素先问删掉会不会更好
```

## CSS 变量块

```css
:root {
  --bg:#ffffff; --text:#111111; --text-2:#888888;
  --accent-block:#3d5afe; /* Kelly 式点睛色块，整块使用 */
  --radius:0px;
  --font:'Inter','Helvetica Neue','PingFang SC',sans-serif;
}
```

## 反模式

- 极简但信息塞满（自相矛盾）；灰阶超过 2 级（层级靠字号不靠灰度）
- 无意义的浮动装饰；为平衡而对称（不对称留白更高级）
