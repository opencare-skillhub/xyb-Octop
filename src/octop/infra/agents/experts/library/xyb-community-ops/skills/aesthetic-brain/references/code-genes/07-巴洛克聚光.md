# 🎨 code-gene · 巴洛克聚光（Tenebrism 暗底 hero）

> **激活词**：卡拉瓦乔、伦勃朗光、Tenebrism、chiaroscuro、舞台追光、金色黑暗
> **适用产物**：发布会/大片感 hero 区、人物故事页、纪录片风格长图、奢侈品页
> **上游种子**：[ch03 巴洛克（卡拉瓦乔/伦勃朗）](../chapters/ch03-巴洛克.md) · [moods/08 暗黑崇高](../moods/08-暗黑崇高.md)

## 部署提示词

```text
以「巴洛克聚光」基因渲染本产物：
- 色彩：近黑褐底 #14100c（带暖倾向的黑，禁 #000）；正文暖灰 #d8cfc0；
  金色 #c9a227 只做线（描边/分隔线/标题一角），禁大面积鎏金；焦点内容区给暖光晕
- 光：整页暗，只有一个"光源区"——hero 图/核心数据被一束暖光照亮，
  从光源向外亮度衰减（radial-gradient 从 rgba(201,162,39,.12) 到透明）；
  其余区域沉入黑暗
- 形：圆角 8px 内敛；卡片浮起靠"受光面更亮"（#1d1812 → #241d15），禁白卡片
- 字：衬线标题（Playfair/思源宋体）配大字重；正文暖灰无衬线；
  关键数字金色、放大、衬线
- 排版：一屏一主角（人物或一句台词），像舞台；滚动 = 幕布推进，每幕重新布光；
  装饰线用金色细线（1px）勾重点，禁满屏金纹
- 禁：暗底上塞满内容（黑暗要占 60%+）；冷白光（要烛光暖调）
```

## CSS 变量块

```css
:root {
  --bg:#14100c; --surface:#1d1812; --surface-lit:#241d15;
  --text:#d8cfc0; --gold:#c9a227;
  --radius:8px;
  --spotlight:radial-gradient(ellipse at 50% 30%, rgba(201,162,39,.12), transparent 60%);
  --font-serif:'Playfair Display','Noto Serif SC',serif;
}
```

## 反模式

- 冷白/冷蓝光源（巴洛克的黑是烛光剧场，不是停尸房）
- 金色大面积铺底（婚庆展板化）；多光源多处辉光（Tenebrism 只有一个光源叙事）
