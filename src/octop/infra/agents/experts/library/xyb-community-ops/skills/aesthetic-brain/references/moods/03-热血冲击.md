# 🔥 热血冲击 · 情绪选种档案

> **读者该感受到**：肾上腺素、呼啸的速度、"就是现在！"的爆发瞬间。
> **适用场景**：赛事/活动 KV、招新海报、战斗类游戏宣传、口号型长图、动员页。
> **基因公式**：主基因=Trigger 爆裂色（或鸟山明利落线），辅基因=未来主义速度线，只混一层。

---

## 🥇 主推种子详解

### A. Trigger 爆裂色（Kill la Kill 系）

**为什么适配**：撞色 + 夸张变形 + 放射速度线的目的就是"让血管变粗"，是动画史上最直给的冲击语法。

**五基因拆解**：

| 基因位 | 具体参数 |
|--------|---------|
| 色彩系统 | 互补色硬碰：红×青、黄×紫；饱和度拉满；黑白用作闪帧 |
| 光线逻辑 | 无所谓真实光——轮廓光、爆发光、放射白光，服务于气势 |
| 笔触/线条 | 粗黑轮廓线 + 变形夸张（透视拉伸、肢体延长）；速度线放射集中 |
| 构图法则 | 主体巨大化顶天立地、对角线冲出画面、放射状集中构图（焦点即主角） |
| 情绪温度 | 沸腾、嚣张、快乐的热血 |

- **AI Prompt Keywords**：`Trigger style, Kill la Kill, bold outlines, dynamic pose, speed lines, vibrant clashing colors, over-the-top action`
- **媒介适配**：海报/KV 最适；CSS 上用「斜切色块 + 大号倾斜标题 + 速度线装饰」复刻

### B. 鸟山明利落线（龙珠系）

**为什么适配**：热血但需要"清爽可信"时（体育、竞技、少年向产品）——线条做减法到极致，力量感全靠姿势与剪影。

**五基因拆解**：

| 基因位 | 具体参数 |
|--------|---------|
| 色彩系统 | 明快原色平涂 + 少量渐变；衣服色就是标识色，全图 ≤4 色 |
| 光线逻辑 | 简单的二分阴影（cel shading），高光点睛即可 |
| 笔触/线条 | 干净利落的统一粗细描边，衣褶肌肉简化到最少笔画 |
| 构图法则 | 战斗分镜式：斜向动势、冲击帧、扬起的尘土碎石化为速度符号 |
| 情绪温度 | 阳光、昂扬、少年气 |

- **AI Prompt Keywords**：`Toriyama style, Dragon Ball, clean lines, dynamic action pose, cel shaded, energetic`
- **媒介适配**：角色主导的 KV；图标/吉祥物联动时亲和力最高

### C. 未来主义速度（巴拉 / 薄邱尼）

**为什么适配**：抽象层面的速度——不需要人物也能"热血"，适合数据、产品、迭代叙事的动员图。

- **Keywords**：`futurism, Boccioni, dynamism, motion blur repetition, speed force lines`
- **用法**：把主体沿运动方向重复 3-5 次残影 + 拉长，配合斜向裁切

## 🥈 备选速览

| 种子 | 一句话基因 | 何时用它当主推 |
|-------|-----------|--------------|
| 巴洛克戏剧（鲁本斯） | 螺旋动势+饱满人体 | 需要古典厚重的史诗感热血 |
| 北斗肌肉美学（原哲夫） | 钢筋人体+强对比 | 硬派、成人向、力量举 |
| Bones 作画 | 流畅战斗+独特运镜 | 动作分镜连续叙事 |
| ufotable 特效 | 水火光CG后期 | 需要电影质感的必杀技帧 |

## ⚠️ 本情绪翻车清单

- ❌ 冲击=到处都大：全图都在喊等于没喊，留一处"静"做反差（大留白+小字）反而更炸
- ❌ 撞色超过一对（红青已经够了，再叠黄紫=廉价）
- ❌ 速度线方向混乱——同一画面速度线只允许一个消失点
- ❌ 用细衬线字/优雅字体配热血画面（字体气质必须同温）
