> **上游种子**：[ch14 抽象艺术](../chapters/ch14-抽象艺术.md) · [moods/09 清晰理性](../moods/09-清晰理性.md)

## 部署提示词（贴给任何 agent 直接生效）

```text
以「瑞士平面/包豪斯」基因渲染本产物：
- 色彩：白/浅灰底 #ffffff~#f7f8fa；正文三级灰 #1a1a1a/#4a4a4a/#9e9e9e；
  唯一强调色（品牌红 #e63946 或指定色）只用于数据高亮/CTA/关键数字，面积 ≤10%
- 形：零圆角或 2px 微圆角；1px #e5e7eb 细分隔线；无阴影无渐变（flat）
- 字：无衬线一家到底（Helvetica/Inter/思源黑体）；四级字号阶梯 32/20/14/11；
  标题字重 700 正文 400，字距默认，行高 1.5 正文 / 1.2 标题
- 排版：12 列栅格，元素要么对齐栅格线要么明确越格；左对齐统治；
  留白 32px 起步；序号用大号数字（48px+ 灰色）做导航锚点
- 图表：单色阶 + 一个强调色；柱状图>饼图；数据标签直接标在图形上，禁图例迷宫
```

## CSS 变量块

```css
:root {
  --bg:#f7f8fa; --surface:#ffffff;
  --text-1:#1a1a1a; --text-2:#4a4a4a; --text-3:#9e9e9e;
  --accent:#e63946;
  --radius:2px; --line:#e5e7eb;
  --font:'Helvetica Neue','Inter','PingFang SC','Noto Sans SC',sans-serif;
}
```

## 反模式

- 彩虹图表、3D 饼图、投影拟物（2010 年前 Excel 审美）
- 五级以上字号层级、居中对齐长正文
- 强调色超过一种 / 渐变按钮
