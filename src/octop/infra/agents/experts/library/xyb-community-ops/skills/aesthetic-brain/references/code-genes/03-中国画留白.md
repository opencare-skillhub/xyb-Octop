> **适用产物**：文化内容长图、茶叶/酒/中药材页、诗词内容、国风品牌官网
> **上游种子**：[ch20 中国画](../chapters/ch20-中国画.md) · [moods/06 孤独诗意](../moods/06-孤独诗意.md) · [moods/10 东方古韵](../moods/10-东方古韵.md)

## 部署提示词

```text
以「中国画留白」基因渲染本产物：
- 色彩：绢色底 #f5f0e6（禁纯白 #fff，要纸绢的暖）；墨色文字 #2b2b2b；
  点缀只允许：朱砂印章红 #c3272b（一处）+ 花青/赭石极淡一处；饱和度整体压低
- 形：禁重边框卡片——分区靠留白与 1px 淡墨线（#d8d0c0），禁阴影禁渐变色块
- 字：标题用宋体/仿宋大字（可竖排 writing-mode:vertical-rl 点睛一列）；
  正文 15px+ 行高 2.0（疏朗是本基因的命）；禁黑体浓重字重压绢底
- 排版：内容占一侧（≤60% 宽），另一侧整块留白（气口）；段落间空 32px+；
  章节间用"远山淡墨横条"或一枚印章做分隔；图必须配大量空白，不许图文挤压
- 禁：留白里塞二维码/水印/装饰底纹（留白是内容本身）
```

## 反模式

- 大红大金铺底（金色做线不做面）；祥云水纹底纹填满气口
- 卡片化布局（圆角白卡叠在绢底上 = 西式卡片污染东方基因）
- 印章当贴纸乱盖（一图一印，位置参与构图）
