# 第二章  样式主义 Mannerism (1520-1600)
样式主义是文艺复兴盛期后的过渡风格。艺术家刻意打破拉斐尔的和谐与平衡，用拉长的人体比例、不稳定的构图、强烈的色彩对比来表达戏剧性和紧张感。这是一种「矫饰的优雅」——不追求自然真实，而追求人工化的美感。
🎨 帕尔米贾尼诺 Parmigianino (1503-1540)  ·  样式主义
他的《长颈圣母》是样式主义的标志性作品：拉长的颈部、超大的手指、不合理的空间比例，创造了一种奇异而优雅的美感。
🎯 AI Prompt Keywords: Parmigianino, Mannerism, elongated figures, elegant distortion, Madonna
🎨 布龙齐诺 Bronzino (1503-1572)  ·  样式主义 / 肖像画
美第奇家族的宫廷肖像画家，以冷峻优雅的人物描绘著称。人物表情疏离、服饰细节华丽繁复，画面有一种大理石般的冷感美。
🎯 AI Prompt Keywords: Bronzino, Mannerist portrait, cool elegance, Medici court, polished finish
🎨 丁托列托 Tintoretto (1518-1594)  ·  威尼斯样式主义
以巨大的画幅和戏剧性的明暗对比著称。他的构图充满对角线、剧烈的透视缩短法和几乎电影感的角度，预示了巴洛克的到来。
🎯 AI Prompt Keywords: Tintoretto, dramatic composition, diagonal energy, Venetian Mannerism, large scale
🎨 埃尔·格列柯 El Greco (1541-1614)  ·  西班牙样式主义 / 独特个人风格
现代人眼中最「超前」的文艺复兴画家。他用扭曲拉长的人物、阴森蓝绿色的色调、仿佛燃烧的天空创造出一种极度个人化的神秘主义风格，完全无法归类。
🎯 AI Prompt Keywords: El Greco, elongated figures, mystical, dramatic sky, strange colors, spiritual intensity
