# 🎨 code-gene · 构成主义海报

> **激活词**：Rodchenko、El Lissitzky、红色楔子、对角线动势、photomontage、宣传鼓动
> **适用产物**：活动 KV、招聘/招募页、宣言式长图、运动赛事、社会议题传播
> **上游种子**：[ch14 抽象艺术（俄罗斯先锋派）](../chapters/ch14-抽象艺术.md)

## 部署提示词

```text
以「构成主义海报」基因渲染本产物：
- 色彩：红 #d93025 + 黑 + 米白纸底 #f0e9dc 三色封顶；零渐变零阴影；
  允许做旧纸纹理（噪点 3%）
- 形：硬边几何——楔形、三角、斜切色带；照片一律黑白+双色调处理，
  剪贴边缘留白边（拼贴感）；禁圆角（radius:0）
- 字：粗黑无衬线全大写（可加字距）；标题倾斜 15-30° 沿对角线排布；
  字号悬殊（超大标语 + 小注释）；文字可被几何色块裁切
- 排版：一条强对角线统治全图（元素沿线分布）；视线被几何强制引导；
  信息密度中低，口号式文案
- 禁：柔和色调、对称构图、优雅留白（这里是动势与呐喊）
```

## CSS 变量块

```css
:root {
  --bg:#f0e9dc; --red:#d93025; --black:#141414;
  --radius:0px;
  --diagonal:linear-gradient(24deg, transparent 49.7%, var(--red) 49.7%, var(--red) 60%, transparent 60%);
  --font:'Archivo Black','Noto Sans SC',sans-serif;
}
```

## 反模式

- 加入第四种颜色（三色纪律是力量来源）；圆角与阴影（破坏版画质感）
- 文案啰嗦（构成主义只吃口号：动词+名词，一行）
