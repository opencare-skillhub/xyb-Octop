# 🎨 code-gene · 赛璐璐动漫 UI

> **激活词**：cel shading、京阿尼光影、SHAFT 45 度、鸟山明 cel、动画色板、两分阴影
> **适用产物**：二次元产品/游戏 UI、角色主站长图、虚拟主播页、动漫社区
> **上游种子**：[ch22 动漫风格](../chapters/ch22-动漫风格.md) · [ch23 二次元插画](../chapters/ch23-当代二次元插画师.md)

## 部署提示词

```text
以「赛璐璐动漫」基因渲染本产物：
- 色彩：角色/主体色板驱动 UI——从立绘取 3 色做 UI 主轴（主色 60% + 辅色 30% + 高光色 10%）；
  阴影一律两分 cel（纯色阶，无柔和渐变阴影）；白底或角色场景延伸底
- 形：面板用"动画字幕框"逻辑——白底 2px 深色描边 + 小切角（clip-path 切一个角，
  禁全圆角软萌）；按钮按下态用 cel 阴影位移（实心 offset 阴影 3px）
- 字：黑体粗标题 + 高光色描边或色块衬底；正文干净黑体；
  允许拟声词、感叹号、星星✦做装饰符号
- 排版：斜切分区（-8°~8° 内）制造动感；对话框气泡承载引言/台词；
  立绘允许越出面板边界（层次感关键手法）
- 禁：真实照片素材混排（插画世界要自洽）；高级灰低饱和（动漫基因要明快）
```

## CSS 变量块

```css
:root {
  --bg:#ffffff; --ink:#2a2a35;
  --main:#5a7dfa; --sub:#8fd0f0; --hi:#ffd166;  /* 示例：从立绘取色替换 */
  --outline:2px solid var(--ink);
  --radius:4px;
  --cel-shadow:4px 4px 0 var(--ink);  /* 实心位移阴影 */
}
```

## 反模式

- 写实阴影/渐变拟物（赛璐璐只有色阶）；UI 色与立绘色脱节（必须同源取色）
- 全圆角药丸按钮（动漫 UI 的锐利感全无）
