# 🌸 甜美容爱 · 情绪选种档案

> **读者该感受到**：心被戳软、想收藏、少女心的"可爱到发出声音"。
> **适用场景**：婚恋/交友产品、甜品与花店、少女向游戏、节日贺卡、宠物内容、母婴。
> **基因公式**：主基因=洛可可粉彩（或少女漫画华丽眼），辅基因=浮世绘美人绘的线，只混一层。

---

## 🥇 主推种子详解

### A. 洛可可粉彩（布歇 / 弗拉戈纳尔 / 华托）

**为什么适配**：甜蜜的千年标准答案——粉彩、绸缎、花园，贵族级"甜"而不腻的关键在于**明度高、饱和度中低**。

**五基因拆解**：

| 基因位 | 具体参数 |
|--------|---------|
| 色彩系统 | 粉红 #f4c2c2 / 婴儿蓝 / 淡鹅黄 / 薄荷绿，全部高明度中低饱和；白色做呼吸缝隙 |
| 光线逻辑 | 均匀柔光，无硬阴影；缎面高光呈珍珠光泽 |
| 笔触/线条 | 轻快松散的笔触（Fragonard 式），边缘柔和融化 |
| 构图法则 | C 形/S 形曲线构图（洛可可标志性）；拱形花环、云朵边框 |
| 情绪温度 | 轻盈、嬉戏、微醺的甜 |

- **AI Prompt Keywords**：`Rococo, Fragonard, pastel pink and blue, soft dreamy light, ribbons and flowers, playful romance`
- **媒介适配**：CSS 长图 → 粉白渐变（单色系内渐变，禁蓝紫渐变）+ 大圆角 + 手写体点缀；生图直用关键词

### B. 少女漫画华丽眼（种村有菜 / CLAMP / 武内直子）

**为什么适配**：二次元语境的甜——闪亮大眼 + 花边 + 星光特效，情绪浓度最高，年轻受众识别度即萌点。

**五基因拆解**：

| 基因位 | 具体参数 |
|--------|---------|
| 色彩系统 | 粉紫粉蓝为主 + 大量白色高光 + 金色点缀（星星/王冠）；允许一个高饱和标识色 |
| 光线逻辑 | 自带闪光特效：十字星、泡泡、羽毛飘落 |
| 笔触/线条 | 纤细流动的线稿（藤蔓般），睫毛华丽，发丝一缕缕分色 |
| 构图法则 | 人物大特写 + 花卉/蕾丝满铺边框；气泡对话框也是装饰件 |
| 情绪温度 | 梦幻、心动、戏剧化的纯情 |

- **AI Prompt Keywords**：`shoujo manga style, sparkling eyes, frills and ribbons, flower border, pastel colors, 90s magical girl aesthetic`
- **媒介适配**：少女向游戏 UI、社群头图；CSS 上用「花朵角标 + 虚线描边 + 圆体字」

### C. 浮世绘美人绘（歌麿）

**为什么适配**：要"甜美但高级、带和风"时——大首绘特写 + 纤细优雅线条，甜得含蓄。

- **Keywords**：`Utamaro, ukiyo-e bijin-ga, elegant lines, subtle expression, flat pastel woodblock`
- **用法**：与洛可可混一层（轮廓用浮世绘线，色彩用粉彩）即得和风甜品铺气质

## 🥈 备选速览

| 种子 | 一句话基因 | 何时用它当主推 |
|-------|-----------|--------------|
| 公主风游戏 art（つなこ） | 明亮华丽服装+大眼 | 游戏角色立绘主导的页面 |
| 甜美韩系（Pistachio） | 粉嫩甜品色+极简可爱 | 甜品店、文具、日常小物 |
| 圆润国民风（藤子·F·不二雄） | 圆滚滚+想象力+国民亲和 | 全年龄产品、亲子 |
| NANA 时尚冷甜（矢泽爱） | 时尚搭配感+冷艳甜 | 少女但拒绝幼态的潮牌场景 |

## ⚠️ 本情绪翻车清单

- ❌ 纯饱和荧光粉（#ff69b4 级）大面积铺——甜变廉价，粉彩降饱和是保命线
- ❌ 甜系不等于元素堆满：花边 + 星星 + 波点 + 缎带全上 = 视觉便秘，装饰选两种封顶
- ❌ 黑色正文直接压粉色底（对比刺眼破坏柔感，改深咖/深玫瑰 #5d3a3a 一族）
- ❌ 成人婚恋场景误用少女漫星光（改洛可可或浮世绘美人绘的含蓄路线）
