# 第九章  后印象派 Post-Impressionism (Late 19th Century)
后印象派不是统一风格，而是几位不满于印象派「只画眼睛所见」的画家各自找到新方向。他们更注重情感表达、结构秩序和象征意义，为20世纪现代艺术铺平了道路。
🎨 文森特·梵高 Vincent van Gogh (1853-1890)  ·  后印象派 / 情感色彩
艺术史上最悲剧也最被爱戴的画家。他用粗犷旋转的笔触和极端饱和的色彩表达内心的风暴。每一笔都像在燃烧。《星月夜》《向日葵》《麦田上的乌鸦》——他的画是他灵魂的X光。
🎯 AI Prompt Keywords: Van Gogh, expressive brushwork, thick impasto, vibrant colors, Starry Night, emotional intensity
🎨 保罗·塞尚 Paul Cézanne (1839-1906)  ·  后印象派 / 现代艺术之父
塞尚被誉为「现代艺术之父」，因为他教会了后来者如何用几何形体理解自然。他将物体简化为圆柱体、球体、圆锥体，用微妙的笔触和色彩过渡构造形式。毕加索说他「是我们的父亲」。
🎯 AI Prompt Keywords: Cézanne, Post-Impressionism, father of modern art, geometric simplification, Mont Sainte-Victoire
🎨 保罗·高更 Paul Gauguin (1848-1903)  ·  后印象派 / 原始主义
逃离文明，前往塔希提岛追求原始和野性的艺术。他用大片平涂的色彩、强烈的轮廓线和象征性的内容，创造了一种神秘而富有装饰性的风格。
🎯 AI Prompt Keywords: Gauguin, Post-Impressionism, Tahiti, Cloisonnism, flat colors, primitive, symbolic
🎨 乔治·修拉 Georges Seurat (1859-1891)  ·  点彩派 / 科学色彩
发明了点彩派（Pointillism）——用无数纯色小点按科学原理排列，在观众眼中混合成色彩。他的《大碗岛的星期天下午》是一幅严格按色彩理论构建的巨作。
🎯 AI Prompt Keywords: Seurat, Pointillism, color theory, tiny dots, A Sunday on La Grande Jatte, scientific
🎨 亨利·德·图卢兹-劳特累克 Henri de Toulouse-Lautrec (1864-1901)  ·  后印象派 / 夜巴黎
以描绘蒙马特夜生活著称。身高残疾的他出没于红磨坊和咖啡馆，用尖锐的线条和大胆的色彩记录舞女、歌者和妓女的世界。他的海报设计极具现代感。
🎯 AI Prompt Keywords: Toulouse-Lautrec, Moulin Rouge, poster art, cabaret life, bold lines, Montmartre
🎨 皮埃尔·博纳尔 Pierre Bonnard (1867-1947)  ·  纳比派 / 亲密色彩
纳比派的核心成员。他的室内场景和花园沐浴在奇异而美丽的色彩中，每一寸画面都像打翻的调色盘。他的妻子玛尔特是他永恒的模特。
🎯 AI Prompt Keywords: Bonnard, Nabis, intimate interiors, radiant color, domestic scenes, bathing scenes
🎨 爱德华·维亚尔 Édouard Vuillard (1868-1940)  ·  纳比派 / 室内装饰
纳比派画家，以描绘资产阶级室内场景著称。他善于用繁复的图案和柔和的色彩将人物融入背景，创造出如壁毯般华丽的画面。
🎯 AI Prompt Keywords: Vuillard, Nabis, interior decoration, patterns, intimate scenes, bourgeois life
🎨 奥迪隆·雷东 Odilon Redon (1840-1916)  ·  象征主义 / 梦想世界
象征主义大师，早期以黑白石版画和炭笔画创作梦境般的奇异生物，后期转向色彩丰富、神秘的花卉和神话主题。他的世界是视觉化的潜意识。
🎯 AI Prompt Keywords: Redon, Symbolism, dreamlike, fantastic creatures, mysterious flowers, pastel, charcoal
