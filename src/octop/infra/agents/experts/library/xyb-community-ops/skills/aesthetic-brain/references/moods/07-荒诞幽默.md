# 🃏 荒诞幽默 · 情绪选种档案

> **读者该感受到**：先愣一下，然后笑出来，笑完还想一下。
> **适用场景**：社交传播图、愚人节/整活内容、播客封面、亚文化品牌、吐槽长图。
> **基因公式**：主基因=超现实马格利特（或涂鸦哈林），辅基因=波普复制，只混一层。

---

## 🥇 主推种子详解

### A. 沉默谜题（马格利特）

**为什么适配**：最高级的幽默是"安静的错位"——礼帽人、遮脸苹果、这不是一只烟斗。不靠夸张表情，靠**日常物的错误逻辑**。

**五基因拆解**：

| 基因位 | 具体参数 |
|--------|---------|
| 色彩系统 | 平涂的中等饱和色（砖红、墨绿、灰蓝），像 1950 年代插图画 |
| 光线逻辑 | 室内灯光般均匀，错位的物体却亮得理直气壮 |
| 笔触/线条 | 光滑细腻的写实笔触——越认真画越荒诞（反差是笑点本体） |
| 构图法则 | 单一错位物居中；正常场景 + 一个不该在的物；文字与图像互相拆台 |
| 情绪温度 | 冷面幽默（deadpan）、狡黠、哲学玩笑 |

- **AI Prompt Keywords**：`Magritte surrealism, bowler hat, face obscured by object, visual paradox, deadpan, quiet absurdity`
- **媒介适配**：梗图封面、深度长文的"反差配图"；CSS 可用「正常卡片 + 一个错位元素」复刻逻辑

### B. 街头涂鸦（Keith Haring）

**为什么适配**：外放的、快乐感染力型幽默——空心轮廓小人 + 放射线，三笔画出来就能让全世界看懂。

**五基因拆解**：

| 基因位 | 具体参数 |
|--------|---------|
| 色彩系统 | 原色平涂（红黄蓝绿橙）+ 黑轮廓 + 白/荧光底 |
| 光线逻辑 | 无光影，纯平面 |
| 笔触/线条 | 粗黑空心轮廓线，一笔到位不修改，动势夸张 |
| 构图法则 | 图案化重复（小人跳舞阵列）；边框即画框，填满到溢出 |
| 情绪温度 | 狂欢、直给、人人可参与的快乐 |

- **AI Prompt Keywords**：`Keith Haring style, bold black outlines, dancing figures, radiant lines, pop street art, primary colors`
- **媒介适配**：活动主视觉、社群表情包体系；CSS 上用「粗描边图标 + 原色色块」

### C. 波普复制（沃霍尔）

**为什么适配**：重复即笑点——同一个头像换八个配色排成网格，荒诞感自动产生（鬼畜的祖宗）。

- **Keywords**：`Warhol, Pop Art silkscreen, grid repetition, color variation, flat screenprint`
- **用法**：主推时选一个主角物件做 2×2 或 3×3 网格换色；注意底层图像要够 iconic

## 🥈 备选速览

| 种子 | 一句话基因 | 何时用它当主推 |
|-------|-----------|--------------|
| 妖怪浮世绘（国芳/晓斋） | 动态夸张+戏谑妖怪 | 和风整活、猫企划（国芳是猫痴） |
| 软雕塑（Oldenburg） | 巨大日常物+软塌塌 | 产品戏仿、食物类幽默 |
| 冷面文字（Baldessari） | 脸上贴彩点+莫名句子 | 概念摄影梗、艺术生冷幽默 |
| 搞笑漫节奏（赤冢不二夫） | 荒唐节奏+表情崩坏 | 四格/条漫叙事型内容 |

## ⚠️ 本情绪翻车清单

- ❌ 幽默靠贴表情包贴纸——拼贴感是懒，错位才是设计
- ❌ 又荒诞又华丽（荒诞要克制背景，华丽会抢走"错位"这个主角）
- ❌ 冷面幽默配圆体可爱字（字体要一本正经，反差才成立）
- ❌ 玩梗密度过高——一图一个梗，观众只记住最好的那个
