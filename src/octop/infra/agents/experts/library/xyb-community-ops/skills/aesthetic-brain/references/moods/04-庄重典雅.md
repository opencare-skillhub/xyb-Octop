# 🏛️ 庄重典雅 · 情绪选种档案

> **读者该感受到**：仪式感、可信度、"这是认真做出来的东西"。
> **适用场景**：周年庆/纪念内容、官方年报封面、机构介绍、婚礼与典礼、历史文化题材、高端品牌页。
> **基因公式**：主基因=新古典素描（或北宋全景山水），辅基因=穆夏装饰线，只混一层。

---

## 🥇 主推种子详解

### A. 新古典（大卫 / 安格尔 / 卡诺瓦）

**为什么适配**：西方语境里"庄重"的原点——清晰轮廓、均衡构图、克制用色，理性本身就是权威感。

**五基因拆解**：

| 基因位 | 具体参数 |
|--------|---------|
| 色彩系统 | 大地色 + 米白 + 一点深红/深蓝；低饱和，像被时间柔化的油画 |
| 光线逻辑 | 均匀的剧场侧光，形体如雕塑般清晰；无炫技光效 |
| 笔触/线条 | 隐没笔触的光滑画面（Ingres 式线条绝对主义），轮廓精确 |
| 构图法则 | 横向三层浮雕式排布；对称或严格均衡；人物如柱式稳定 |
| 情绪温度 | 肃穆、克制、纪念碑感 |

- **AI Prompt Keywords**：`Neoclassicism, Jacques-Louis David, Ingres draftsmanship, balanced composition, muted classical palette, marble`
- **媒介适配**：年报/典礼 KV 主视觉；CSS 上配衬线字 + 大量对称留白 + 细金线分隔

### B. 北宋全景山水（范宽 / 郭熙）

**为什么适配**：东方语境的庄重——巨嶂式大山占画面三分之二，人行如蚁，"仰之弥高"的敬畏感是任何西式构图给不了的。

**五基因拆解**：

| 基因位 | 具体参数 |
|--------|---------|
| 色彩系统 | 墨分五色为主，绢底暖褐；青绿变体（李思训）用于庆典语境 |
| 光线逻辑 | 无固定光源——"以后映带左右"，体积靠皴法（雨点皴/卷云皴） |
| 笔触/线条 | 皴法即笔触：雨点皴密实厚重；轮廓线方硬如铁 |
| 构图法则 | 全景三段式：近景溪桥—中景云雾—主峰巍然；S 形路径引视线登山 |
| 情绪温度 | 崇高、永恒、人在天地间的谦卑 |

- **AI Prompt Keywords**：`Fan Kuan style, monumental Northern Song landscape, ink wash, misty mountains, tiny travelers, rain-dot texture strokes`
- **媒介适配**：机构介绍横幅、周年庆长卷（横向长图天然适合手卷叙事）

### C. 穆夏新艺术

**为什么适配**：庄重但要有"美与装饰"的场合（文化节、艺术活动、女性主题纪念）——拜占庭光环 + 流动发丝 + 花卉边框。

- **Keywords**：`Mucha, Art Nouveau poster, ornate circular halo, flowing hair, decorative border, muted pastel gold`
- **用法**：主推时人物居中 + 环形文字框；注意装饰密度控制在边框层，中心留呼吸

## 🥈 备选速览

| 种子 | 一句话基因 | 何时用它当主推 |
|-------|-----------|--------------|
| 文艺复兴和谐（拉斐尔） | 稳定三角构图+温柔理想美 | 教育、人文、经典再版 |
| 温柔大理石（卡诺瓦） | 温润白大理石+凝滞瞬间 | 婚礼、爱情纪念、雕塑感产品 |
| 壁画静穆（Puvis de Chavannes） | 粉笔苍白+古典静止 | 需要"博物馆墙面"气质的序列插画 |
| 宫廷肖像（荷尔拜因） | 冷静精确+服饰符号学 | 人物志、机构创始人介绍 |

## ⚠️ 本情绪翻车清单

- ❌ 庄重≠加金色滤镜：金色只做线（描边/分隔线），大面积鎏金立刻变婚庆展板
- ❌ 衬线字 + 两端对齐 + 行距过密——典雅的排版核心是**疏**，行距 1.8 倍起
- ❌ 配色超过 3 种——庄重的底气就是克制
- ❌ 图标用卡通描边风——用细线（1px）线性图标或不要图标
