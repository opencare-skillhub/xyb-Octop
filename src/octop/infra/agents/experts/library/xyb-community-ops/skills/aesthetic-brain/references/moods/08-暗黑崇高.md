# 💀 暗黑崇高 · 情绪选种档案

> **读者该感受到**：压迫、敬畏、废墟中残存的神圣——美得让人不敢直视。
> **适用场景**：史诗题材、恐怖游戏宣传、重金属/暗黑音乐、历史创伤叙事、万圣节企划。
> **基因公式**：主基因=浪漫主义废墟（基弗/透纳），辅基因=哥特浮世绘（芳年），只混一层。

---

## 🥇 主推种子详解

### A. 浪漫主义废墟（基弗 / 透纳）

**为什么适配**：暗黑的顶格不是吓人，是"崇高"（Sublime）——文明残骸 + 吞噬一切的光，规模感本身就是神性。

**五基因拆解**：

| 基因位 | 具体参数 |
|--------|---------|
| 色彩系统 | 铅灰、烬黑、焦褐 + 一线脓黄/血红的光；整体低明度，光只占 10% |
| 光线逻辑 | 光从灾难中来：燃烧的天空（透纳）/ 废墟缝隙的逆光（基弗）；光越少越贵 |
| 笔触/线条 | 厚涂刮擦 + 材料肌理（稻草、灰烬感）；笔触粗暴即真实 |
| 构图法则 | 巨幅横构图；地平线压到极低（天占 3/4）；微小废墟剪影 |
| 情绪温度 | 沉重、悲怆、纪念碑式的哀悼 |

- **AI Prompt Keywords**：`Anselm Kiefer, Turner, monumental ruins, ash and lead tones, apocalyptic light, sublime darkness, thick texture`
- **媒介适配**：生图/厚涂最强；CSS 上用「近黑底 #0d0b08 + 单一火光色 + 颗粒纹理」

### B. 哥特浮世绘（芳年）

**为什么适配**：东方暗黑——血月、幽灵、美与恐怖同框，芳年的残忍是精致的，适合需要"和风暗黑"辨识度的场景。

**五基因拆解**：

| 基因位 | 具体参数 |
|--------|---------|
| 色彩系统 | 靛蓝夜色 + 朱红/猩红点睛 + 月白；浮世绘固有的平涂色块 |
| 光线逻辑 | 月光/鬼火冷光；暗部用普鲁士蓝平涂（浮世绘式） |
| 笔触/线条 | 锐利繁密的线描（毛发、火焰一根根勾），恐怖靠细节密度 |
| 构图法则 | 大特写对角压迫；人物与巨大月亮/火焰图形成面积反差 |
| 情绪温度 | 阴惨、执念、凄美的战栗 |

- **AI Prompt Keywords**：`Yoshitoshi, ukiyo-e horror, indigo night, blood moon, ghostly figure, delicate terrifying linework`
- **媒介适配**：和风恐怖企划、怪谈封面

### C. Tenebrism 舞台追光（卡拉瓦乔）

**为什么适配**：需要"人物级"暗黑肖像时——黑背景 + 一道追光，把脸从黑暗里切出来，戏剧张力最古典的来源。

- **Keywords**：`Caravaggio, Tenebrism, dramatic chiaroscuro, single spotlight, deep shadow, raw realism`
- **用法**：主推时背景纯黑 + 主体 30% 面积受光；辅基因时给废墟场景里的人物打追光

## 🥈 备选速览

| 种子 | 一句话基因 | 何时用它当主推 |
|-------|-----------|--------------|
| 黑画（戈雅） | 啃噬感的暗+心理恐怖 | 内在恐惧、战争创伤叙事 |
| 扭曲教皇（培根） | 抹布撕扯的肉+封闭空间 | 存在主义焦虑、当代暗黑 |
| 哥特少女（由贵香织里） | 堕落天使+羽毛逆十字 | 二次元暗黑幻想、哥特萝莉塔 |
| 粗野东京（森山大道） | 粗粒晃动失焦 | 都市暗面纪实、街头暗黑摄影 |

## ⚠️ 本情绪翻车清单

- ❌ 暗黑=把亮度拉低：没有光的**设计**（光源叙事）只是看不清，不是暗黑
- ❌ 恐怖元素堆叠（骷髅+血+蜘蛛+乌鸦同框=万圣节超市海报），留一个恐怖符号放大
- ❌ 用赛博霓虹的荧光色点睛（两套语言冲突，暗黑只许暖光/血色/月白三种点睛）
- ❌ 大面积正黑 #000 平涂——用带倾向的黑（铅灰黑/褐黑/蓝黑）才有物质感
