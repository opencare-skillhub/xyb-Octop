# 第二十一章  东方艺术传统：日本浮世绘 Ukiyo-e (17th-19th Century)
浮世绘，「浮世绘画」——描绘江户时代日本普通人的生活和风景。最初是木版画，价格低廉、印刷量大，是当时的「大众艺术」。它对欧洲印象派和后印象派产生了革命性的影响。
🎨 菱川师宣 Hishikawa Moronobu (1618-1694)  ·  浮世绘 / 创始人
被称为浮世绘的创始人。他确立了浮世绘版画的基本形式——黑色的轮廓线加上手绘填色，到了他的后期发展为单色墨印。
🎯 AI Prompt Keywords: Moronobu, ukiyo-e founder, black outlines, hand-colored, early Japanese printmaking
🎨 铃木春信 Suzuki Harunobu (1725-1770)  ·  浮世绘 / 锦绘发明者
发明了多色印刷的「锦绘」（Nishiki-e），让浮世绘从单色走向色彩缤纷。他的画以纤细清秀的美人画著称，描绘的是江户市井生活中的诗意瞬间。
🎯 AI Prompt Keywords: Harunobu, Nishiki-e brocade prints, polychrome, beautiful women, delicate, poetry
🎨 胜川春章 Katsukawa Shunshō (1726-1793)  ·  浮世绘 / 役者绘
以歌舞伎演员的肖像画「役者绘」著称，捕捉了演员在舞台上的动态瞬间和个性表情。
🎯 AI Prompt Keywords: Shunshō, ukiyo-e, kabuki actor prints, theatrical, expressive faces
🎨 喜多川歌麿 Kitagawa Utamaro (1753-1806)  ·  浮世绘 / 美人画巅峰
浮世绘美人画的大师。他专注于女性头像和上半身的特写（大首绘），能够捕捉女性微妙的面部表情和内心世界。他的线条纤细优雅。
🎯 AI Prompt Keywords: Utamaro, ukiyo-e, beautiful women, close-up portraits, elegant lines, subtle expressions
🎨 东洲斋写乐 Tōshūsai Sharaku (1794-1795)  ·  浮世绘 / 神秘天才
浮世绘史上最神秘的画家——只在1794-1795年活跃了10个月就消失了。他创作的歌舞伎演员肖像极度夸张变形，像现代漫画一样抓住了人物的性格特征。
🎯 AI Prompt Keywords: Sharaku, ukiyo-e, kabuki actors, grotesque exaggeration, psychological intensity, mysterious
🎨 葛饰北斋 Katsushika Hokusai (1760-1849)  ·  浮世绘 / 富岳三十六景
全球最著名的日本艺术家。《神奈川冲浪里》是人类文化史上最知名的图像之一。他九十岁还在说「再给我五年寿命，我会成为真正的画家」。他的画幅多变，从富士山到鬼怪到海浪。
🎯 AI Prompt Keywords: Hokusai, ukiyo-e, The Great Wave off Kanagawa, Mount Fuji, dynamic, versatile, manga
🎨 歌川广重 Utagawa Hiroshige (1797-1858)  ·  浮世绘 / 风景抒情
北斋之后的浮世绘风景画大师。他的《东海道五十三次》《名所江户百景》系列捕捉了日本四季变化中的诗情画意。雨雪、月夜、樱花——他最擅长描绘天气和氛围。
🎯 AI Prompt Keywords: Hiroshige, ukiyo-e, landscape, Tokaido road, seasons, rain and snow, poetic atmosphere
🎨 歌川国芳 Utagawa Kuniyoshi (1798-1861)  ·  浮世绘 / 武士与妖怪
以威武的武士画、妖怪画和猫画著称。他的武士画面充满动态和夸张的肌肉，近乎漫画。他有很多猫和妖怪的幽默画作，后来影响了日本动漫。
🎯 AI Prompt Keywords: Kuniyoshi, ukiyo-e, warriors, mythical creatures, cats, tattoos, dramatic poses
🎨 丰原国周 Toyohara Kunichika (1835-1900)  ·  浮世绘 / 明治役者绘
幕末明治时期的役者绘大师。他的作品色彩浓烈、构图大胆，是浮世绘黄昏时代的最后辉煌。
🎯 AI Prompt Keywords: Kunichika, ukiyo-e, actors, Meiji period, rich colors, bold compositions
🎨 月冈芳年 Tsukioka Yoshitoshi (1839-1892)  ·  浮世绘 / 血腥与月
浮世绘最后的伟大艺术家。他的《英名二十八众句》《月百姿》系列充满了鬼怪、杀戮、美丽与恐怖的结合。他的画残忍、梦幻、令人难忘。
🎯 AI Prompt Keywords: Yoshitoshi, ukiyo-e, bloody prints, One Hundred Aspects of the Moon, ghost, violence, beauty
🎨 河锅晓斋 Kawanabe Kyōsai (1831-1889)  ·  浮世绘 / 讽刺与狂画
以狂放不羁的讽刺画和妖怪画著称。他酒后作画，笔走龙蛇，画面极富动感和幽默感。
🎯 AI Prompt Keywords: Kyōsai, ukiyo-e, satirical, drunken painting, frog and crow, ghosts, bold brushwork
