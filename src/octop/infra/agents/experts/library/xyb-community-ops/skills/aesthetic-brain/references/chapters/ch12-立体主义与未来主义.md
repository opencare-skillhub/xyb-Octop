# 第十二章  立体主义与未来主义 Cubism & Futurism (1907-1915)
立体主义是毕加索和布拉克发起的视觉革命——他们将物体分解、从多个角度同时观察、然后重组在同一个平面上。这是自文艺复兴以来对西方绘画视点最根本的挑战。未来主义则在意大利欢呼机器时代的到来，赞美速度、运动和暴力。
## 立体主义 Cubism
🎨 巴勃罗·毕加索 Pablo Picasso (1881-1973)  ·  立体主义 / 20世纪艺术的巨人
20世纪最具影响力的艺术家。他的《亚威农少女》开启了立体主义的序幕。他与布拉克共同发展了分析立体主义（将物体分解成小块面）和综合立体主义（拼贴引入绘画）。他多变的风格贯穿了整个20世纪。
🎯 AI Prompt Keywords: Picasso, Cubism, Les Demoiselles d'Avignon, multifaceted, geometric deconstruction, prolific
🎨 乔治·布拉克 Georges Braque (1882-1963)  ·  立体主义 / 与毕加索同行者
与毕加索并肩发展立体主义，但风格更加温和、更注重肌理和材料的实验。他早期是野兽派画家，转身后与毕加索几乎在做同一幅画。
🎯 AI Prompt Keywords: Braque, Cubism, collages, textures, still life, muted palette, analytic cubism
🎨 胡安·格里斯 Juan Gris (1887-1927)  ·  立体主义 / 严谨建构者
立体主义的第三位核心人物。与毕加索和布拉克的直觉不同，格里斯的立体主义更加理性和数学化，像建筑师一样严格建构画面结构。
🎯 AI Prompt Keywords: Juan Gris, Cubism, synthetic cubism, mathematical precision, still life, structured
🎨 费尔南·莱热 Fernand Léger (1881-1955)  ·  机器立体主义
将立体主义与机器美学结合。他画中的人物和物体都像由金属管、齿轮和圆圈构成。他对现代工业社会的赞美和对机械美的追求影响了后来的波普艺术。
🎯 AI Prompt Keywords: Léger, Cubist, machine forms, tubular shapes, bold colors, modern life, industrial
🎨 罗贝尔·德劳内 Robert Delaunay (1885-1941)  ·  奥费主义 / 色彩交响
从立体主义发展出更色彩化的「奥费主义」（Orphism）。他使用圆盘和色彩对比创造纯粹的视觉节奏，像绘画中的音乐。
🎯 AI Prompt Keywords: Delaunay, Orphism, color discs, simultaneous contrast, abstract, rhythmic
🎨 雅克·维永 Jacques Villon (1875-1963)  ·  分析立体主义 / 版画
法国立体主义画家和版画家，杜尚的兄弟。他以精确的分析立体主义风格创作，并将立体主义原理应用于铜版画和彩色石版画。
🎯 AI Prompt Keywords: Jacques Villon, analytic cubism, printmaking, precise geometric forms
## 未来主义 Futurism
🎨 翁贝托·薄邱尼 Umberto Boccioni (1882-1916)  ·  未来主义 / 运动雕塑
未来主义最重要的画家和雕塑家。他的《城市的崛起》《空间中连续的独特形式》捕捉了现代城市的力量、速度和运动的动态感。他在一战中阵亡。
🎯 AI Prompt Keywords: Boccioni, Futurism, dynamism, speed, Unique Forms of Continuity in Space, modern city
🎨 贾科莫·巴拉 Giacomo Balla (1871-1958)  ·  未来主义 / 光的动态
他研究如何描绘运动——不是在某个瞬间，而是在连续的运动中。他的《拴着皮带的狗》用多重交叠的脚和尾巴表现小狗奔跑的动态。
🎯 AI Prompt Keywords: Balla, Futurism, movement study, Dynamism of a Dog on a Leash, light, abstract speed
🎨 卡洛·卡拉 Carlo Carrà (1881-1966)  ·  未来主义 → 形而上画派
早期是未来主义的核心成员，后来转向形而上绘画（Metaphysical Painting），与基里科一起创造了空寂、神秘的绘画风格。
🎯 AI Prompt Keywords: Carrà, Futurism, Metaphysical painting, still life, mannequins, enigmatic
🎨 吉诺·塞韦里尼 Gino Severini (1883-1966)  ·  未来主义
未来主义画家中对色彩最有敏感度的。他的《塔巴林舞女之舞》用闪烁的色彩和碎片化的形式表现了夜总会的灯光和运动。
🎯 AI Prompt Keywords: Severini, Futurism, dance, nightlife, fragmented light, colorful
🎨 路易吉·鲁索洛 Luigi Russolo (1885-1947)  ·  未来主义 / 噪音艺术
未来主义画家同时也是音乐家，他发明了「噪音机器」（Intonarumori），并发表了《噪音的艺术》宣言，预言了20世纪的电子音乐。
🎯 AI Prompt Keywords: Russolo, Futurism, noise music, sound art, Avant-garde
## 形而上画派 Metaphysical Painting
🎨 乔治·德·基里科 Giorgio de Chirico (1888-1978)  ·  形而上画派 / 空寂广场
形而上画派的创始人。他画中空无一人的意大利广场、拉长的阴影、火车和雕像的组合创造出一种令人不安的梦幻感。他的风格直接影响了超现实主义。
🎯 AI Prompt Keywords: De Chirico, Metaphysical painting, empty squares, long shadows, mannequins, dreamlike
