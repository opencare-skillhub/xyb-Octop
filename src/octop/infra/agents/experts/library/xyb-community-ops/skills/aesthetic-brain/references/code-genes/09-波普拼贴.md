> **适用产物**：潮流品牌页、活动宣传、社交传播图、音乐/娱乐内容、整活企划
> **上游种子**：[ch16 波普艺术](../chapters/ch16-波普艺术.md) · [moods/07 荒诞幽默](../moods/07-荒诞幽默.md)

## 部署提示词

```text
以「波普拼贴」基因渲染本产物：
- 色彩：亮白底 + 原色平涂（红 #ff3b30 / 黄 #ffcc00 / 蓝 #007aff 的波普调）+ 黑轮廓；
  允许同一元素换色复制成网格（2×2 或 3×3，沃霍尔逻辑）；饱和度全开但色相 ≤4
- 形：粗黑描边 3-4px；本戴点纹理（radial-gradient 圆点阵）做阴影/渐变替代；
  对话气泡框是合法 UI 组件；图形边缘硬朗（印刷套色感）
- 字：粗壮无衬线大写标题 + 漫画拟声词（BAM! / WOW! 一处即可）；
  描边文字（text-shadow 四向黑边）点睛
- 排版：中心爆炸式或满铺网格二选一；贴纸感元素允许轻微旋转（±3°）；
  价格标签/Logo 印章式方框是本基因的经典组件
- 禁：柔和渐变、轻透玻璃感（波普是油墨的物理感）；灰暗低饱和
```

## CSS 变量块

```css
:root {
  --bg:#ffffff; --pop-red:#ff3b30; --pop-yellow:#ffcc00; --pop-blue:#007aff;
  --ink:#111111;
  --outline:3px solid var(--ink);
  --benday:radial-gradient(circle, rgba(17,17,17,.22) 1.2px, transparent 1.3px);
  --benday-size:8px 8px;
}
```

## 反模式

- 波普底配衬线优雅字（语言打架）；半透明磨砂玻璃卡片
