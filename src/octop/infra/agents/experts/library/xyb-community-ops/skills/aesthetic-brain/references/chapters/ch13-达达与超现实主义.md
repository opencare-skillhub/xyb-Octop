# 第十三章  达达与超现实主义 Dada & Surrealism (1916-1945)
达达是一战后对理性世界的绝望反击——既然理性导致了战争，那艺术就应该是反理性的、荒谬的、无意义的。超现实主义则是达达的升级版——它让潜意识成为艺术的源泉，用梦境和自动书写创造前所未有的图像。
## 达达主义 Dadaism
🎨 马塞尔·杜尚 Marcel Duchamp (1887-1968)  ·  达达 / 观念艺术之父
整个20世纪观念艺术之父。他把小便池签上名字送去展览（《泉》），给蒙娜丽莎画上胡子（L.H.O.O.Q.），彻底颠覆了「什么是艺术」的定义。他说：「艺术就是我在做的事。」
🎯 AI Prompt Keywords: Duchamp, Dada, readymade, conceptual art, Fountain, irreverent, anti-art
🎨 汉斯·阿尔普 Hans Arp (1886-1966)  ·  达达 / 有机抽象
达达和超现实主义的桥梁人物。他创造了「有机抽象」——自由流动的、像生物形态般的抽象形状。他也是自动绘画的早期实践者。
🎯 AI Prompt Keywords: Arp, Dada, organic abstraction, biomorphic forms, chance, automatic drawing
🎨 库尔特·施维特斯 Kurt Schwitters (1887-1948)  ·  达达 / 拼贴垃圾美学
用街上的垃圾、废票、报纸碎片创作「Merz」系列拼贴画。他把最不起眼的生活废物转化成美丽的艺术品，影响了后来的装置艺术。
🎯 AI Prompt Keywords: Schwitters, Dada, Merz, collage, found objects, urban detritus, assemblage
🎨 弗朗西斯·毕卡比亚 Francis Picabia (1879-1953)  ·  达达 / 讽刺机械
风格多变且具有讽刺精神的达达画师，以机器肖像画和透明重叠的绘画著称。
🎯 AI Prompt Keywords: Picabia, Dada, machine drawings, ironic, mechanical portraits, transparent layers
🎨 曼·雷 Man Ray (1890-1976)  ·  达达/超现实主义 / 摄影实验
美国出生的达达和超现实主义摄影师和画家。他发明了「雷摄影」（Rayograph）——不用相机直接在感光纸上放置物体曝光，创造了如梦似幻的影像。
🎯 AI Prompt Keywords: Man Ray, Dada, Surrealist photography, Rayograph, solarization, objects
## 超现实主义 Surrealism
🎨 萨尔瓦多·达利 Salvador Dalí (1904-1989)  ·  超现实主义 / 偏执批判法
超现实主义最具辨识度的人物。他用像照片一样精确的细节描绘完全不可能的场景——融化的时钟、拉长的大象、梦中才能出现的荒诞景象。他的「偏执批判法」是自我创造的幻觉方法。
🎯 AI Prompt Keywords: Dalí, Surrealism, melting clocks, Persistence of Memory, paranoid-critical, dreamlike precision
🎨 雷内·马格利特 René Magritte (1898-1967)  ·  超现实主义 / 沉默的谜题
比利时超现实主义大师。他的画安静得令人不安——戴圆顶礼帽的男人、遮住面部的苹果、写有「这不是一只烟斗」的烟斗画。他问的是：图像和文字真的能代表真实吗？
🎯 AI Prompt Keywords: Magritte, Surrealism, The Son of Man, Ceci n'est pas une pipe, bowler hat, visual paradox
🎨 胡安·米罗 Joan Miró (1893-1983)  ·  超现实主义 / 童趣抽象
用符号和生物形态创造了一个独属于他的宇宙。他的画看起来像儿童的涂鸦——黑色的点、线、彩色的几何形状——但每一笔都经过高度提炼。
🎯 AI Prompt Keywords: Miró, Surrealism, abstract symbols, biomorphic, colorful, playful, Catalan
🎨 马克斯·恩斯特 Max Ernst (1891-1976)  ·  超现实主义 / 拼贴与摩拓
超现实主义最多产的实验者之一。他发明了「摩拓法」（Frottage）——在木板或布料上擦铅笔拓印纹理，然后在这些偶然的纹理上找到图像。
🎯 AI Prompt Keywords: Max Ernst, Surrealism, frottage, collage novels, fantastical landscapes, dream imagery
🎨 伊夫·唐吉 Yves Tanguy (1900-1955)  ·  超现实主义 / 白骨风景
法国超现实主义画家，他画中的风景总是荒凉而空旷——辽阔的沙地上散布着奇怪的骨状有机体，在遥远的地平线下投下长长的阴影。
🎯 AI Prompt Keywords: Tanguy, Surrealism, bone-like forms, desolate landscape, infinite horizon, dream space
🎨 安德烈·马松 André Masson (1896-1987)  ·  超现实主义 / 自动绘画
自动绘画（Automatic drawing）的实践者。他让笔无意识地游走在纸上，让潜意识的图像浮现出来，然后再赋予它们形式。
🎯 AI Prompt Keywords: Masson, Surrealism, automatic drawing, subconscious, flowing lines, mythological
🎨 保尔·德尔沃 Paul Delvaux (1897-1994)  ·  超现实主义 / 裸女与火车
比利时超现实主义画家，以空寂的古典建筑街道上行走的裸女和远处的火车场景著称。画面有一种介于梦境与死亡之间的静止感。
🎯 AI Prompt Keywords: Delvaux, Surrealism, nude women, classical architecture, trains, eerie stillness
🎨 弗里达·卡罗 Frida Kahlo (1907-1954)  ·  超现实主义 / 自传式幻想
墨西哥最著名的女画家。她的自画像充满了痛苦、坚韧和墨西哥本土文化元素。她将自己的身体创伤和情感经历用超现实的视觉呈现在画布上。
🎯 AI Prompt Keywords: Frida Kahlo, self-portraits, Mexican folk art, pain and resilience, surrealist, unibrow
🎨 利奥诺拉·卡林顿 Leonora Carrington (1917-2011)  ·  超现实主义 / 凯尔特神话
英国出生的女性超现实主义画家，后移居墨西哥。她的画充满凯尔特神话和炼金术意象，马的形象反复出现。她的作品比男性超现实主义者更温和而神秘。
🎯 AI Prompt Keywords: Leonora Carrington, Surrealism, Celtic mythology, hybrid creatures, alchemy, Mexico
🎨 维克托·布劳纳 Victor Brauner (1903-1966)  ·  超现实主义 / 图腾与巫术
罗马尼亚出生的超现实主义画家。他的作品融合了古埃及、印第安图腾和巫术符号，具有强烈的神秘主义和预言色彩。
🎯 AI Prompt Keywords: Brauner, Surrealism, totemic, occult symbols, hybrid creatures, Romanian
