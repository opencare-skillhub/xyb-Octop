## 部署提示词

```text
以「吉卜力手绘亲和」基因渲染本产物：
- 色彩：米白底 #faf7f0；草木绿 #7fb069 与天空蓝 #8ecae6 做双色主轴；
  阴影永远用暖色（#e8e0d0 级），禁纯黑纯灰阴影；点缀暖黄 #ffd166 做阳光感高光
- 形：大圆角 12-16px（圆润是本基因的形）；按钮/卡片有 2px 柔和描边（深一号的底色，非黑）；
  图标用插画感填充风，禁细线性冷感图标
- 字：圆体优先（圆润黑体/思源柔黑气质）；正文 16px 行高 1.8；
  标题可配手写体点缀词（一处）
- 排版：模块像"便签/绘本页"松散分布，禁严整对称网格；
  每屏留一处手绘插画或贴纸感元素；图文环绕自然错落
- 禁：荧光色、锐利直角、数据仪表盘式密度——这是慢下来的基因
```

## 反模式

- 高饱和撞色混入（治愈饱和度整体压一档）；阴影发灰发黑
- 字太密 + 留白 <30%（治愈系文字必须少）
- 商务感元素（表格/严谨图表）直接混入
