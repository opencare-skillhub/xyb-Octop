# 🌑 科技酷感 · 情绪选种档案

> **读者该感受到**：未来感、速度、精密、疏离的冷光。
> **适用场景**：科技产品长图、发布会 KV、赛博题材插画、数据可视化暗色版、技术类 PPT、开发者工具官网。
> **基因公式**：主基因=赛博霓虹（或构成主义），辅基因=机器美学/黑白结构，只混一层。

---

## 🥇 主推种子详解

### A. 赛博霓虹（押井守《攻壳机动队》/ 新海诚夜景）

**为什么适配**：自发光光源天然制造"未来感"，暗部大面积留黑让荧光色像信号一样刺出来，与"科技=信息发光"的直觉同构。

**五基因拆解**：

| 基因位 | 具体参数 |
|--------|---------|
| 色彩系统 | 深蓝黑底（#0a0e1a ~ #101828 一类，带蓝紫倾向的黑）；高饱和荧光点缀色 ≤2 种：荧光青 #38f2c8 / 品红 #ff2d78 / 电紫 #9b5cff；明度对比拉到极大 |
| 光线逻辑 | 一切亮部都是**自发光**（霓虹招牌、屏幕、全息投影）；体积光、边缘光勾人形；暗部占画面 60% 以上但不死黑，保留蓝紫环境反射 |
| 笔触/线条 | 干净锐利的矢量线条或高精度厚涂，边缘清晰；禁止柔焦水彩类笔触 |
| 构图法则 | 低角度仰视高楼、强透视纵深（一点透视拉到夸张）、玻璃/雨面反射增加层次；人物小、城市大，制造"人在系统中"的压迫感 |
| 情绪温度 | 冷、疏离、精密；孤独感是加分项不是缺陷 |

- **AI Prompt Keywords**：`cyberpunk, neon lights, night city, synthwave, high contrast, volumetric lighting, reflective wet streets`
- **媒介适配**：CSS 长图 → 深底 + 单一荧光青点缀 + 1px 细描边 + 大间距；生图 → 直接用关键词；PPT → 暗底模板，每页只许一个荧光色块
- **翻车规避**：荧光色 ≥3 种立刻变廉价夜店风；等距三栏通用卡片 = AI 味，改用不对称栅格 + 大号数字编号

### B. 构成主义海报（罗德琴科 / 利西茨基）

**为什么适配**：红黑白三色 + 对角线动势，是"科技感"的印刷术祖师爷，比霓虹更高级、更适合需要印刷质感的科技宣传。

**五基因拆解**：

| 基因位 | 具体参数 |
|--------|---------|
| 色彩系统 | 红黑 + 米白纸底，三色封顶，几乎无渐变 |
| 光线逻辑 | 无光影（平涂），靠色块面积对比制造张力 |
| 笔触/线条 | 硬边几何：三角、楔形、斜切色带；照片可用蒙太奇剪切 |
| 构图法则 | 对角线动势、大字倾斜排布、视线路径被几何强制引导 |
| 情绪温度 | 亢奋、动员感、宣传口吻 |

- **AI Prompt Keywords**：`constructivist poster, Rodchenko style, red black diagonal composition, photomontage, bold typography`
- **媒介适配**：CSS/海报最适；配合粗黑无衬线 + 全大写标题

### C. 黑白结构（Franz Kline）

**为什么适配**：当科技题材需要"力量与骨架"而非"霓虹与灯"时（底层架构、性能、工程美学），巨型黑白笔触像钢铁桁架。

- **Keywords**：`Franz Kline, black and white gestural abstraction, monumental brushstrokes`
- **用法**：作为底纹或章节分隔背景，占位 30% 以下，上面压亮色文字

## 🥈 备选速览（何时升级为主推）

| 种子 | 一句话基因 | 何时用它当主推 |
|-------|-----------|--------------|
| 机器美学（Léger） | 人物机械管状化+原色 | 讲"工业/制造/机器人"本体时 |
| 未来主义（薄邱尼/巴拉） | 运动残影+速度线 | 强调"速度/迭代/冲刺"叙事时 |
| 冷艳插画（米山舞） | 时尚造型感+冷色调精渲 | 科技人物立绘、概念角色 |
| ufotable 光影 | CG 后期光效叠加 | 需要电影级战斗/特效画面 |

## ⚠️ 本情绪翻车清单

- ❌ 蓝紫渐变 + 玻璃拟态卡片三连 = 最典型的 AI 味默认审美，撞上即重做
- ❌ 荧光色当大面积主色（只许点缀，≤20% 面积）
- ❌ 等宽间距的图标+卡片网格铺满——改不对称布局或留白
- ❌ 深底上灰字对比度不足（正文对比度至少 7:1）
