# 🌫️ 孤独诗意 · 情绪选种档案

> **读者该感受到**：安静的怅然、广袤中的渺小、与孤独和平共处的美。
> **适用场景**：文艺长文配图、音乐/诗歌内容、深夜电台、独立产品官网、告别与纪念。
> **基因公式**：主基因=一角留白（马远/倪瓒），辅基因=崇高雾景（Friedrich），只混一层。

---

## 🥇 主推种子详解

### A. 一角半边留白（马远 / 夏圭 / 倪瓒）

**为什么适配**：东方孤独美学的极致——画一角而想全貌，**留白本身就是情绪**：不说的部分让读者自己疼。

**五基因拆解**：

| 基因位 | 具体参数 |
|--------|---------|
| 色彩系统 | 墨色阶（焦浓重淡清）+ 纸白；最多一处极淡的赭石/花青点缀 |
| 光线逻辑 | 无光——用"淡"代替光；远山越淡越远 |
| 笔触/线条 | 简寥寥数笔：马远斧劈皴的爽利，或倪瓒折带皴的枯淡；笔越少越贵 |
| 构图法则 | **一角式**：景物压在画面 1/3 以内（角或边），其余全空；倪瓒式：近坡枯树 + 中段大片空白水面 + 远山一线 |
| 情绪温度 | 清冷、孤高、遗世独立 |

- **AI Prompt Keywords**：`Ma Yuan one-corner composition, Ni Zan sparse ink landscape, vast negative space, misty emptiness, solitary tree`
- **媒介适配**：CSS 长图 → 纸白底 + 内容只占一侧 + 竖排标题 + 印章红一点；生图 → 关键词直用；这是文字类内容最高级的底子

### B. 崇高雾景（Friedrich）

**为什么适配**：西方对应物——背影人物面对广袤自然，浪漫主义的"崇高"（Sublime）：孤独被放大成仪式。

**五基因拆解**：

| 基因位 | 具体参数 |
|--------|---------|
| 色彩系统 | 冷灰蓝绿 + 月光白 + 暗部深棕；低饱和高灰度 |
| 光线逻辑 | 雾本身就是光：背光剪影 + 光从雾后透出；黎明/黄昏的低照度 |
| 笔触/线条 | 细腻写实但边缘被雾吃掉（轮廓软化是关键手法） |
| 构图法则 | **背影人物置于前景下方 1/3**，面向无垠远景；哥特废墟/枯树做垂直锚点 |
| 情绪温度 | 静谧、敬畏、内省 |

- **AI Prompt Keywords**：`Caspar David Friedrich, lone figure from behind, misty vast landscape, sublime, moonlight, gothic ruins`
- **媒介适配**：生图最强；封面图首选（背影+雾=天然的"未完成叙事"）

### C. 时间海景（杉本博司）

**为什么适配**：摄影向的极简孤独——海平面把画面一刀两半，禅意摄影师版留白，适合需要"现代感"的孤独表达。

- **Keywords**：`Hiroshi Sugimoto seascape, minimal horizon, long exposure, black and white meditation`
- **用法**：作为通栏背景横条（上天下海），文字压在天空或海面的一侧

## 🥈 备选速览

| 种子 | 一句话基因 | 何时用它当主推 |
|-------|-----------|--------------|
| 白眼鱼鸟（八大山人） | 极简笔墨+倔强孤傲 | 需要态度的孤独（反骨向） |
| 网格冥想（Agnes Martin） | 手绘细线+近乎不可见 | 纯抽象的静心场景、冥想产品 |
| 荒凉梦境（唐吉） | 骨状有机体+无限地平线 | 超现实向的孤独、梦境叙事 |
| 神秘花卉（雷东） | 炭笔到粉彩的潜意识花 | 悼念、内心独白类 |

## ⚠️ 本情绪翻车清单

- ❌ 留白里塞二维码/水印/装饰——留白是内容本身，塞了就全毁
- ❌ 蓝色滤镜一键到底（数字味孤独）；要"灰阶呼吸感"而不是" HDR 惨淡"
- ❌ 文案密排——这种情绪下文字必须零散、行距 2 倍起、像低声说话
- ❌ 配乐感强的动态元素（跳动图标/闪烁）——孤独诗意是静态的深呼吸
