# ✨ 梦幻治愈 · 情绪选种档案

> **读者该感受到**：被托住的安心、夏午的困倦、微微发光的温柔。
> **适用场景**：生活类长图、公益/心理健康内容、儿童与亲子、治愈系游戏 UI、欢迎页、贺卡。
> **基因公式**：主基因=吉卜力手绘（或透明光影），辅基因=印象光/水彩淡彩，只混一层。

---

## 🥇 主推种子详解

### A. 吉卜力手绘（宫崎骏 / Studio Ghibli 背景 art）

**为什么适配**：手绘的温度感 + 对自然细节（夏日绿、流水、云、食物热气）的偏执，是"被世界温柔以待"的视觉等价物。

**五基因拆解**：

| 基因位 | 具体参数 |
|--------|---------|
| 色彩系统 | 高明度中饱和的自然色：草木绿 #7fb069 一族、天空蓝 #8ecae6 一族、奶油白；禁止荧光色与纯黑（阴影用暖紫/深绿代替） |
| 光线逻辑 | 柔和的日光，物皆有淡影；逆光树叶透光（subsurface 感）；室内暖黄灯 |
| 笔触/线条 | 手绘水粉质感背景，可见笔触；人物线条圆润简洁 |
| 构图法则 | 广角自然场景 + 小人物；前景大叶子/窗框制造窥视感；天空占 1/2 画面常见 |
| 情绪温度 | 温暖、辽阔、带一点乡愁 |

- **AI Prompt Keywords**：`Studio Ghibli style, hand-painted background, lush green hills, fluffy clouds, warm sunlight, whimsical, peaceful`
- **媒介适配**：CSS 长图 → 米白底 + 草绿/天蓝双色 + 圆角大（12px+）+ 插画化图标；生图 → 关键词直用；PPT → 手账式版式，禁止锐利直角

### B. 透明光影（Loundraw）

**为什么适配**：数字时代的治愈——"透明感"= 高明度低对比 + 蓝色调 + 光晕溢出，比吉卜力更现代、更安静。

**五基因拆解**：

| 基因位 | 具体参数 |
|--------|---------|
| 色彩系统 | 蓝灰基调 + 高明度；肤色透粉；整体像蒙了一层薄纱（对比度压低 20%） |
| 光线逻辑 | 黄昏/清晨低角度光，光斑（bokeh）化；窗光溢出到人物轮廓 |
| 笔触/线条 | 数字精绘，边缘软化，几乎看不见笔触 |
| 构图法则 | 留白极多的人物半身/远景；视线不看镜头制造"独处感" |
| 情绪温度 | 安静、怅然、青春的余韵 |

- **AI Prompt Keywords**：`Loundraw style, transparent lighting, blue hour, soft glow, cinematic quiet scene`
- **媒介适配**：生图/插画最强；CSS 上用「低对比 + 大留白 + 蓝灰」复刻气质

### C. 莫奈印象光

**为什么适配**：需要"治愈"但题材偏成人/文艺/花园茶会时，印象派光斑比动漫更含蓄高级。

- **Keywords**：`Monet, Impressionism, soft edges, dappled light, pastel harmony, garden`
- **用法**：主基因时配水彩纸纹理底；辅基因时给吉卜力场景加"光斑呼吸感"

## 🥈 备选速览

| 种子 | 一句话基因 | 何时用它当主推 |
|-------|-----------|--------------|
| KyoAni 干净日常 | 柔光影+日常细节偏执 | 校园/日常题材，需要"生活流" |
| 透明水彩（村上ゆき） | 清透薄涂+温柔眼神 | 女性向、母婴、绘本 |
| 治愈风景（八至 yasushi） | 柔和自然色调+氛围 | 纯风景陪伴类内容 |
| 布纹手绘（あずまあや） | 手作纹理+童话感 | 手作品牌、杂货、市集海报 |

## ⚠️ 本情绪翻车清单

- ❌ 阴影用纯黑/纯灰——改暖紫或深绿，一秒保住温柔
- ❌ 高饱和撞色混入（治愈≠甜腻，饱和度整体压一档）
- ❌ 文案区塞满——治愈系留白必须 ≥40%，字要少
- ❌ 锐利直角 + 细黑描边（卡通硬边风会打断柔软氛围）
