# 📊 清晰理性 · 情绪选种档案

> **读者该感受到**：一切尽在掌握——秩序、效率、"这个团队很专业"。
> **适用场景**：数据报告、SaaS 官网、B 端产品、技术文档配图、仪表盘、信息长图。
> **基因公式**：主基因=瑞士平面/包豪斯，辅基因=蒙德里安网格（或一种克制的点缀色语言），只混一层。

---

## 🥇 主推种子详解

### A. 瑞士平面 / 包豪斯（栅格系统 · Moholy-Nagy / Albers 一脉）

**为什么适配**：现代信息设计的宪法——网格、留白、无衬线、功能性优先。专业感的 80% 来自"对齐"这个动作本身。

**五基因拆解**：

| 基因位 | 具体参数 |
|--------|---------|
| 色彩系统 | 中性底（白/浅灰 #f7f8fa）+ 黑正文 + **一个**品牌功能色（信息色，只用于强调与图表主色） |
| 光线逻辑 | 无光影（flat design）；层级靠灰阶（#1a1a1a / #4a4a4a / #9e9e9e 三级文字灰） |
| 笔触/线条 | 硬边几何 + 细分隔线（1px #e5e7eb）；图标统一线性风格 |
| 构图法则 | **12 列栅格，严禁越格**；左对齐统治；留白 32px 起步；信息分层（标题/导语/正文/注释四级字号） |
| 情绪温度 | 冷静、可信、去个人化 |

- **AI Prompt Keywords**：`Swiss International Typographic Style, grid layout, Helvetica, flat design, minimal infographic`
- **媒介适配**：CSS 长图/报告页的本命基因；图表用单色系 + 一个强调色，禁彩虹图表

### B. 蒙德里安网格（De Stijl）

**为什么适配**：需要"理性但有一点性格"时——黑线网格 + 三原色块，秩序里带快乐，适合封面、分区导航、章节隔断。

- **Keywords**：`Mondrian, De Stijl, primary color blocks, black grid lines, Neo-Plasticism`
- **用法**：网格线宽统一（黑 2-4px），色块面积悬殊配比（黄 60% : 红 25% : 蓝 15% 的不对称才高级）

### C. 极简物性（贾德 / Ellsworth Kelly）

**为什么适配**：高端产品页的"少即是多"——一个盒子、一块色、一处弧线，工业级自信。

- **Keywords**：`Donald Judd, minimalism, specific objects, industrial materials, hard-edge Ellsworth Kelly`
- **用法**：产品图 + 巨量留白 + 一行字；克制到近乎空白

## 🥈 备选速览

| 种子 | 一句话基因 | 何时用它当主推 |
|-------|-----------|--------------|
| 干净日常（KyoAni/山田尚子） | 柔光影+体面生活细节 | B 端里需要"人文温度"的案例页 |
| 色彩交互（Albers） | 同色异效的色彩实验 | 讲色彩系统/设计方法论的内容 |
| 建筑构成（El Lissitzky） | Proun 几何+版式张力 | 想比瑞士风格更激进一格 |
| 观念图文（Kruger/徐冰《地书》） | 大字标语/纯图标叙事 | 社会议题信息图、icon-only 指引 |

## ⚠️ 本情绪翻车清单（数据可视化专项）

- ❌ 彩虹图表（一图 8 色）——单色渐变阶 + 一个强调色，读者 3 秒抓住重点
- ❌ 3D 饼图 / 阴影投影 / 渐变拟物——2010 年前的 Excel 审美，全部 flat
- ❌ 对齐靠感觉：任何两个元素要么对齐栅格线，要么明确不对齐（中间态=业余）
- ❌ 字号层级混乱：四级字号（32/20/14/11px 级差）顶天，超过四级信息架构有问题
- ❌ "清晰"误做成"拥挤"：留白被砍——信息越密，留白越要保住
