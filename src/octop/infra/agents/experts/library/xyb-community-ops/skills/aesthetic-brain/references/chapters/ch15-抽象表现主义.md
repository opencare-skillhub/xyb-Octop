# 第十五章  抽象表现主义 Abstract Expressionism (1940s-1960s)
第二次世界大战后，世界艺术中心从巴黎转移到了纽约。抽象表现主义是美国的第一个本土现代艺术运动。它分两大阵营：行动绘画（Action Painting）——由杰克逊·波洛克引领，把画布铺在地上滴溅颜料，画的整个过程本身就是艺术。色彩领域绘画（Color Field Painting）——大面积平涂色彩，追求纯粹的视觉体验。
## 行动绘画 Action Painting
🎨 杰克逊·波洛克 Jackson Pollock (1912-1956)  ·  抽象表现主义 / 滴画
抽象表现主义的标志性人物。他将画布铺在地上，用棍棒、刷子或直接倾倒颜料瓶来作画。这些密密麻麻的线条创造了空前复杂的画面，仿佛捕捉了宇宙的能量。
🎯 AI Prompt Keywords: Pollock, Abstract Expressionism, drip painting, action painting, all-over composition, chaotic energy
🎨 威廉·德·库宁 Willem de Kooning (1904-1997)  ·  抽象表现主义 / 女性系列
荷兰裔美国画家，抽象表现主义的核心人物。他的《女性》系列将抽象表现主义的大笔触与具象结合，用暴力的笔触绘制女性形象——既是赞颂，也是涂改。
🎯 AI Prompt Keywords: De Kooning, Abstract Expressionism, Woman series, aggressive brushwork, figurative abstraction
🎨 弗朗茨·克莱恩 Franz Kline (1910-1962)  ·  抽象表现主义 / 黑白结构
以巨大的黑白抽象绘画闻名。他的画面仿佛是用巨大的毛笔书写的汉字，粗犷的黑色笔触在白色画布上建筑着震撼的空间结构。
🎯 AI Prompt Keywords: Franz Kline, Abstract Expressionism, black and white, gestural abstraction, monumental strokes
🎨 罗伯特·马瑟韦尔 Robert Motherwell (1915-1991)  ·  抽象表现主义 / 西班牙共和国挽歌
抽象表现主义中最具文学气质的画家。他的《西班牙共和国挽歌》系列以黑色的椭圆和直线反复出现在白色背景上，是对西班牙内战的深沉悼念。
🎯 AI Prompt Keywords: Motherwell, Abstract Expressionism, Elegy to the Spanish Republic, black forms, elegiac
## 色彩领域 Color Field
🎨 马克·罗斯科 Mark Rothko (1903-1970)  ·  抽象表现主义 / 色域绘画
史上最深刻的情感抽象画家。他的标志是模糊边界的矩形色块悬浮在另一个色块上。他的画不是要你「看懂」，而是要你「感受」——站在他的巨幅画前，你会被色彩包裹。
🎯 AI Prompt Keywords: Rothko, Color Field painting, floating rectangles, meditative, emotional abstraction, sublime
🎨 克莱福德·斯蒂尔 Clyfford Still (1904-1980)  ·  抽象表现主义 / 裂缝之光
抽象表现主义中最特立独行的一位。他用刮刀涂抹厚厚的颜料，大色块之间通过参差不齐的「裂缝」透出下层的光，给人以原始和崇高的感觉。
🎯 AI Prompt Keywords: Clyfford Still, Abstract Expressionism, jagged forms, color field, raw, monumental
🎨 巴尼特·纽曼 Barnett Newman (1905-1970)  ·  抽象表现主义 / 拉链
他的画只剩下一种元素：大面积单一颜色中一条垂直的细线（他称之为「拉链」ZIP）。他的巨幅画作《拜异教者》是色域绘画的巅峰之一。
🎯 AI Prompt Keywords: Barnett Newman, Color Field, the zip, sublime scale, Vir Heroicus Sublimis, minimal
🎨 阿道夫·戈特利布 Adolph Gottlieb (1903-1974)  ·  抽象表现主义 / 天与地
抽象表现主义的重要先驱。他的「天与地」系列以画布上方的圆形发光体（太阳/天）和下方的粗糙线条笔触（大地/黑暗）构成对立统一。
🎯 AI Prompt Keywords: Gottlieb, Abstract Expressionism, pictograph, burst paintings, sky and earth, symbols
🎨 海伦·弗兰肯塔勒 Helen Frankenthaler (1928-2011)  ·  色域绘画 / 浸染法
她发明了「浸染染色法」(Soak-stain)——将稀释的颜料直接倒在未打底的生画布上，让色彩像水彩一样渗透进画布纤维。这种方法影响了整个色域画派。
🎯 AI Prompt Keywords: Frankenthaler, Color Field, soak-stain technique, Mountains and Sea, lyrical abstraction
🎨 莫里斯·路易斯 Morris Louis (1912-1962)  ·  色域绘画 / 色流
深受弗兰肯塔勒影响，创造了「Veil Paintings」（面纱画）系列——将鲜艳的丙烯颜料倾斜倒在画布上形成透明的色彩瀑布。
🎯 AI Prompt Keywords: Morris Louis, Color Field, veil paintings, poured acrylic, translucent color flows
🎨 肯尼思·诺兰 Kenneth Noland (1924-2010)  ·  色域绘画 / 靶心
以色域绘画中独特的靶心系列和V字形图案著称，用简单的几何形状探索色彩的相互作用。
🎯 AI Prompt Keywords: Noland, Color Field, target paintings, concentric circles, geometric color
