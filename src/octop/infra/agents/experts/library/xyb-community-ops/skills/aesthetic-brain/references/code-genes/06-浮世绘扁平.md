# 🎨 code-gene · 浮世绘扁平（木版画 UI）

> **激活词**：北斋神奈川冲浪、广重东海道、锦绘、木版画、普鲁士蓝、平面色块
> **适用产物**：文化活动页、日料/和风品牌、创意海报式长图、专题封面
> **上游种子**：[ch21 浮世绘](../chapters/ch21-浮世绘.md)

## 部署提示词

```text
以「浮世绘扁平」基因渲染本产物：
- 色彩：和纸米底 #f2ead8；普鲁士蓝 #274a78 做主色（浮世绘蓝）；朱红 #d34e24 点睛；
  全图色相 ≤3 种；所有色块平涂无渐变（套版色的逻辑：一版一色）
- 形：色块边缘可以带一点手作不规则感（border-radius: 255px 15px 225px 15px/15px 225px 15px 255px 的手绘框技巧）；
  粗轮廓 2-3px；禁阴影、禁玻璃拟态
- 字：标题用带笔触感的明朝体/隶书气质；竖排标题 + 横排正文混合；
  字号反差大（大标题 56px+）
- 排版：大块面分割（天空/海/地三段式横向分层）；主体图形压角（一角式）；
  波浪/云纹 SVG 做一条装饰带即可（一条，禁满铺）
- 禁：照片质感素材与扁平色块混排（要么全插画要么色块+文字）
```

```css
  --text:#2f3a4a; --line:#274a78;
  --hand-drawn-border:3px solid var(--indigo);

}
```

## 反模式

- 渐变与阴影（套版印刷没有的东西都不要）
- 超过 3 个色相；细小精致的图标（浮世绘是粗犷大块面的艺术）
- 蓝紫渐变夜空配"和风"字样（语言混串）
