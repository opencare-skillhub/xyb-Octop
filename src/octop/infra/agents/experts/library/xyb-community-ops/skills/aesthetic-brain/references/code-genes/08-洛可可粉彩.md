> **上游种子**：[ch04 洛可可](../chapters/ch04-洛可可.md) · [moods/05 甜美容爱](../moods/05-甜美容爱.md)

## 部署提示词

```text
以「洛可可粉彩」基因渲染本产物：
- 色彩：粉白底 #fdf6f6；粉红 #f4c2c2 + 婴儿蓝 #cfe0f0 双主色（允许同色系内柔和渐变，
  禁蓝紫跨色渐变）；点缀鹅黄 #f7e8b5 与玫瑰金线 #c08497；全图饱和度中低
- 形：大圆角 16px+；卡片描边用玫瑰金细线 1px 或不用；C 形/S 形装饰弧线做分区；
  花瓣/缎带 SVG 角饰限两处
- 字：标题优雅衬线（圆宋/思源宋细体）；正文深玫瑰 #5d3a3a（禁纯黑压粉底）；
  可一处手写体点缀（"Sweet"类小词）
- 排版：曲线分区（弧形分界，禁硬直线切）；留白 40%+；图文像下午茶摆盘一样疏朗；
  中心构图为主（对称的甜美）
- 禁：荧光粉 #ff69b4 级饱和色、黑色大面积、装饰元素超过两种（花边+星星封顶）
```

## 反模式

- 高饱和荧光粉大面积（甜变廉价）；黑字压粉底刺眼
- 装饰堆叠（花边+星星+波点+缎带全上 = 视觉便秘，两种封顶）
- 冷硬商务元素混入（直角表格、黑色 CTA）
