# 可切除性与术前评估

外科判断能不能切，不是看一个指标，是把几组信息放在一起看。这个技能帮你把这几组信息**逐项对齐**，并说清哪一项还缺。

## 一、需要对齐的五组信息

### 组 1 · 肿瘤与主要血管的关系（最关键）

报告里通常写「接触」「包绕」「侵犯」「界限不清」，要逐条对照：

| 血管 | 为什么关键 |
|---|---|
| 肠系膜上动脉（SMA） | 受累程度直接影响能否安全切除 |
| 肠系膜上静脉（SMV） | 可重建与否影响术式 |
| 门静脉（PV） | 同上，常与 SMV 一起描述 |
| 腹腔干（CA） | 受累通常改变分档 |
| 肝总动脉（CHA） | 常与腹腔干一起看 |

**要问患者补的**：报告里有没有写这几条血管？各写了多少度（180°、>180°）？有没有写「可重建」？

**注意**：不同中心、不同指南对接触角度的界值定义不完全一致，所以我不给分档结论——**给的是「报告里写了什么、还缺什么」**。

### 组 2 · 有无远处转移

- 肝、腹膜、肺、远处淋巴结
- 腹膜转移常需腹腔镜探查才能确认，影像可能看不出——这一点要提示患者

### 组 3 · 肿瘤位置与可及术式方向

- 胰头 / 胰体 / 胰尾，决定了讨论的是哪一类术式方向
- 我不说「该做什么术式」，只说「这个位置通常涉及哪类讨论」

### 组 4 · 体能状态与合并症

- 日常活动能力（能否自理、下床、进食）
- 心肺功能、糖尿病控制、营养状态
- 年龄本身不是禁忌，**体能和合并症比年龄更相关**

### 组 5 · 术前是否需要先处理

| 情况 | 通常讨论什么 | 你要问的 |
|---|---|---|
| 黄疸明显 | 是否需要先减黄、用哪种方式 | 我的胆红素多少？需不需要先引流？ |
| 营养差、体重下降明显 | 是否需要营养支持 | 我的白蛋白多少？要不要先补营养？ |
| 血糖控制差 | 围手术期血糖管理 | 术前血糖要控制到什么范围？ |
| 静脉血栓风险 | 是否需评估与预防 | 我需要做血栓风险评估吗？ |

## 二、输出格式

```
【可切除性资料对照】

已提供：
  ✓ 影像：<报告里明确写了什么>
  ✓ 病理：<...>
  ...

缺失（每条说明为什么影响判断）：
  ✗ 肿瘤与 SMA 的关系 — 报告未提及，这是判断的关键项
  ✗ 体能状态 — 未提供，影响能否耐受手术
  ...

可以问外科医生的问题：
  1. 我的影像里，肿瘤与肠系膜上动脉、门静脉的关系分别是什么？
  2. 按我的情况，是否还有需要补充的检查（如腹腔镜探查）？
  3. 如果需要先减黄，用哪种方式、大概需要多久？
  4. 以我目前的体能和合并症，手术的风险主要在哪方面？
  5. 如果评估后不能直接手术，通常会先讨论哪些方向？
```

## 三、红线

- ❌ 不给「可切除 / 交界可切除 / 不可切除」的结论——这是外科医生看片看人后的判断
- ❌ 不推荐具体术式名称作为建议（可以说「这个位置通常涉及哪类讨论」）
- ❌ 不预测手术成功率、并发症概率的具体数字，除非有明确出处并按证据分级标注
- ❌ 不因资料不全就拒答——先给「现有资料能讨论什么」

## 四、依据

- 判断维度（血管关系、转移、体能）来自胰腺癌外科与 MDT 的通行分类思路，具体界值各中心与各版本指南存在差异。
- 引用任何具体界值或数据时，必须标注来源名与年份，并按 `xyb-evidence-guard` 分级；拿不到来源就不写数字。
